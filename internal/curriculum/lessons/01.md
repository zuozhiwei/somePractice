# 开一个校园树洞

第一关的成品是一个可以双击打开、打包传给同学的网页。下面的资料可以随时查阅。

### 认识电脑上的三个窗口

**文件管理器**用来找文件，**浏览器**用来打开网页，**编辑器**用来写代码。本课程的编辑器叫 Visual Studio Code，简称 VS Code。单击选中，快速点两下是双击打开。

:::windows

文件管理器叫「文件资源管理器」，浏览器可以用 Edge。鼠标右键可打开选中项目的菜单。选好内容后，用 Ctrl+C 复制、Ctrl+V 粘贴。Win 是键盘上带小窗标志的键。

:::

:::mac

文件管理器叫 Finder，浏览器可以用 Safari。按住 Control 再点击，可以打开选中项目的菜单。选好内容后，用 ⌘C 复制、⌘V 粘贴。⌘ 是 Command，⇧ 是 Shift。

:::

### 项目放在哪里

**文件夹**装文件，**路径**记录从哪里开始、往哪几层找。最外层的 `campus-treehole` 叫项目**根目录**。交作业前可以对照下方结构，平时继续编辑原来的项目。

```text
campus-treehole/
├── .gitignore
├── README.md
└── web/
    └── index.html
```

最后一个点后面的文字是**扩展名**，告诉电脑文件的类型。`index.html` 的扩展名是 `.html`，而 `index.html.txt` 的扩展名是 `.txt`。

**README** 可理解为「先读我」，负责写清作品和打开方法。`.md` 是 Markdown 文件的扩展名。`.gitignore` 最前面有英文点，未来 Git 可以读它来忽略指定文件。

**ZIP** 把几份文件装成一个包，`campus-treehole.zip` 适合传给同学。解开后可以还原包里的文件夹和内容。收到 ZIP 时可以[在新目录解压并打开网页](/level/1?task=4)，浏览器地址会告诉你打开的是哪一份。

### 软件官网和安装包

软件官网由作者发布软件下载和使用说明。浏览器地址里，在 `https://` 之后、下一个斜杠之前的网站名称叫**域名**。`code.visualstudio.com` 是 Visual Studio Code 的官方域名。**下载**会把安装包存到电脑，**安装**会运行安装包或把应用放进系统的应用程序目录。后续还会用到这套找软件的办法。

### 认识网页标签

HTML 的中文名称是「超文本标记语言」。查下面这张表，可以分清浏览器标签页上的标题和网页里的大标题。

| 在编辑器里看到 | 浏览器在哪里用到它 |
| --- | --- |
| `<title>校园树洞</title>` | 浏览器顶部的标签页名称 |
| `<h1>校园树洞</h1>` | 页面里最重要的大标题 |
| `<p>欢迎分享校园故事。</p>` | 页面里的一段正文 |
| `<meta charset="utf-8">` | 告诉浏览器按 UTF-8 读取文字，和文件保存的编码配合使用 |

想自己试一次，可以打开[认识 HTML，做出第一张网页](/level/1?task=3)。想继续了解链接、列表和图片，可以读 [MDN 中文入门：HTML 基础](https://developer.mozilla.org/zh-CN/docs/Learn_web_development/Getting_started/Your_first_website/Creating_the_content)。

## 任务 3 | 认识 HTML，做出第一张网页

前置：[找到官网并安装 VS Code](/level/1?task=1)和[开启文件扩展名显示](/level/1?task=165)。

### 操作步骤

**先读懂一行 HTML。** HTML 用标签描述网页内容。`<h1>我的校园树洞</h1>` 这行里，`<h1>` 告诉浏览器从这里开始一个大标题，`</h1>` 表示这个标题结束。两者之间的字会显示在页面上。`<p>` 和 `</p>` 围住一段普通文字。VS Code 用来编辑这些原始文字，浏览器根据标签把它呈现为网页。这次把文件保存为 `index.html`，就可以双击它，用浏览器查看结果。[网页标签参考](/level/1?guide=1#认识网页标签)

**新建文件，放入示例。** 展开 VS Code 左侧根目录，打开 `web` 文件夹的快捷菜单，选「新建文件」，输入 `index.html` 并回车。它应位于 `web` 下。点下面代码的「复制」，然后点编辑区空白处。用编辑器的「编辑 → 粘贴」放入代码，用「文件 → 保存」。窗口下方状态栏通常显示 UTF-8。若显示其他编码，点编码文字，再选「通过编码保存 → UTF-8」。

```html
<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="utf-8">
  <title>我的校园树洞</title>
</head>
<body>
  <h1>我的校园树洞</h1>
  <p>这里是我给同学做的校园留言板。</p>
</body>
</html>
```

**用浏览器看原样，再改一处。**

1. 回文件管理器，在 `web` 中双击 `index.html`。若打开了编辑器，用文件的「打开方式」选择浏览器。浏览器地址通常以 `file:` 开头，表示正在看本机文件。页面应显示「我的校园树洞」和一行介绍。
2. 回 VS Code，只改 `<h1>` 和 `</h1>` 中间的字，例如把「我的校园树洞」换成「晚自习树洞」。保存后切回浏览器，点地址栏旁的刷新按钮。页面的大标题应更新，下面的介绍和浏览器标签页上的标题保持原样。
3. 若大标题没变，核对浏览器路径与编辑器中的文件，确认已经保存。若看到的是一串尖括号，请核对文件是否叫 `index.html.txt`。中文乱码时，检查保存编码是否为 UTF-8，并核对 `<meta charset="utf-8">`。

### 预期结果

浏览器显示自己的产品名和一行介绍。保存再刷新能看到页面大标题更新。

完成练习后，如果想给树洞介绍加上一张图片，可以接着读 [MDN 中文入门里的图片示例](https://developer.mozilla.org/zh-CN/docs/Learn_web_development/Getting_started/Your_first_website/Creating_the_content)。

### 提交

交保留中文的源码片段、浏览器结果和打开网页的实际目录。用一句话指出是哪对标签控制了页面里的大标题。

## 任务 5 | 写 README 并核对保存

前置：[认识 HTML，做出第一张网页](/level/1?task=3)。

### 操作步骤

**写出打开说明。** README 是作品的「先读我」。后缀 `.md` 表示 Markdown，井号和空格可以标出标题。回 VS Code 左侧，打开项目根目录的快捷菜单，点「新建文件」，输入 `README.md`。它应该与 `web` 并排。复制下面的内容。把标题改成网页里的产品名，把服务对象改成你想服务的同学，然后保存。

## 任务 167 | 把整个项目压缩为 ZIP

前置：[找到官网并准备压缩工具](/level/1?task=166)和[写 README 并核对保存](/level/1?task=5)。

### 操作步骤

**选中整个项目。** 在 VS Code 保存打开的文件。回系统的文档目录，单击选中外层 `campus-treehole`。选其中的 `web` 会漏掉项目说明。

**选择压缩方式。**

:::windows

1. 右键 `campus-treehole`。Windows 11 如果没看到 7-Zip，先点「显示更多选项」。指向「7-Zip」，再点「添加到压缩包… / Add to archive…」。
2. 在设置窗口的「压缩格式 / Archive format」选 `zip`。核对名称是 `campus-treehole.zip`，保存位置为原项目所在目录，再点「确定 / OK」。
3. 如果已安装 7-Zip 但菜单没出现，从「开始」打开 7-Zip File Manager。点击界面顶部地址栏，输入项目的上一级路径。可先从资源管理器按 Ctrl+L 选中上一级路径并复制。回车后选中 `campus-treehole`，点「添加 / Add」，在设置窗口完成第 2 步。
4. 机房限制安装时，记录情况。可以在文件夹右键菜单用系统的「压缩到 → ZIP 文件」或「发送到 → 压缩(zipped)文件夹」。

:::

:::mac

在 Finder 的「文稿」里，按住 Control 再点 `campus-treehole`，选「压缩『campus-treehole』」。Finder 会在同一目录生成 ZIP。

:::

**核对结果。** 返回文件列表，应看到 `campus-treehole` 文件夹和 `campus-treehole.zip` 并排。

:::windows

看到 `.7z` 时回 7-Zip 重做，明确在设置窗口选 `zip`。改后缀不会把 7z 转为 ZIP。

:::

:::mac

Finder 生成 `Archive.zip` 时，先确认是否同时选了多个项目。重新单击选中外层项目目录，然后压缩。

:::

### 预期结果

原来可继续编辑的文件夹和新的 `campus-treehole.zip` 并列。ZIP 包含网页及说明。

### 提交

交 ZIP 完整文件名、原目录位置和实际使用的菜单。可附两个项目并排的截图。

## 任务 4 | 在新目录解压并打开网页

前置：[把整个项目压缩为 ZIP](/level/1?task=167)。

### 操作步骤

**将 ZIP 复制到一个空文件夹。** 在和 `campus-treehole.zip` 同一级的文档目录，新建空文件夹 `treehole-check`。

:::windows

单击选中 ZIP，按 Ctrl+C。双击进入 `treehole-check`，按 Ctrl+V。

:::

:::mac

单击选中 ZIP，按 ⌘C。双击进入 `treehole-check`，按 ⌘V。

:::

确认当前位置里有 `treehole-check`，里面有刚复制的 ZIP。现在可将 ZIP 里的内容还原到这里。

**解压刚复制的 ZIP。**

:::windows

右键新目录里的 ZIP。Windows 11 可先点「显示更多选项」。选「7-Zip → 解压到当前文件夹 / Extract Here」。若快捷菜单缺失，从「开始」打开 7-Zip File Manager，进入 `treehole-check`，选 ZIP，再点「解压 / Extract」。输出位置选 `treehole-check` 后确认。用系统自带方案时，右键点「全部解压缩」，核对目标地址在 `treehole-check` 下，再点「提取」。

:::

:::mac

在 Finder 的 `treehole-check` 里双击复制来的 ZIP，旁边应出现解压出的普通文件夹。Finder 会在 ZIP 所在的位置解压，可以从当前路径核对位置。

:::

**复开解压出来的副本。**

1. 进新目录里解压出的普通文件夹，找到并排的 `README.md` 和 `web`。先读 README，再照说明进入 `web` 双击 `index.html`。若它打开了编辑器，用「打开方式」选择浏览器。
2. 核对浏览器地址含 `treehole-check`，页面标题和介绍与原版一致。只看到归档的内容列表时，回到「解压刚复制的 ZIP」，先解压出普通文件夹。若没有 README，回[压缩任务](/level/1?task=167)只选外层项目文件夹重做。
3. 验证完成后，下一关继续编辑最初的 `campus-treehole`。

### 预期结果

独立目录中有实际解压的树洞和说明文件。从含 `treehole-check` 的地址打开网页时，它与原版一致。

### 提交

交解压路径和实际打开的标题，可附地址栏截图。写明以后继续编辑哪个原始目录。
