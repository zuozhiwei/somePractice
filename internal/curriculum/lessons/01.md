# 在自己的电脑上写出第一张网页
先做一次只有两步的实验：用编辑器保存一行字，让浏览器把它显示出来。你需要一台能创建文件的电脑、VS Code 和一个浏览器。本关可以离线练习。

1. 在「文档」中新建 `task-board`，作为后续作品的工作区，在它里面建 `my-first-web`。用 VS Code 的「文件 → 打开文件夹」打开后者。左侧资源管理器顶部应显示这个文件夹名。
2. 新建 `hello.txt`，用学习昵称写下今天的小目标，保存、关闭标签，再从左侧打开。文字留在文件里才算保存成功。
3. 新建 `hello.html`，保存下面两行。在文件管理器中双击它，浏览器会把第一行显示成大标题。

```html
<meta charset="utf-8">
<h1>你好，世界！</h1>
```

把「世界」改成自己的昵称，先刷新浏览器，再保存文件并刷新一次。两次结果有什么不同？在 `notes.txt` 写下你的预测、观察以及实际修改的文件名。以后每加一个功能，都可以用这个小实验检验。

如果页面显示一串尖括号，先查真实文件名是否为 `hello.html.txt`。如果刷新没有变化，看浏览器地址栏末尾的文件，与编辑器正在修改的文件是否同一个。交作业前，把文件夹压缩一份，换个目录解压并打开网页，确认备份真的可用。

## 任务 165 | 显示文件扩展名（后缀名）
在 Windows 11 的资源管理器里展开「查看 → 显示 → 文件扩展名」，Windows 10 可在「查看」选项卡中勾选。在练习目录建立 `测试.txt`、`hello.html`、`readme.md`。截图包含完整文件名，分别说明纯文本、网页和 Markdown 的用途，再指出 `hello.html.txt` 最后一个扩展名是什么。

## 任务 166 | 显示隐藏的项目
在练习目录新建 `hidden-demo`，打开它的属性，勾选「隐藏」。保持在父目录，切换「查看 → 显示 → 隐藏的项目」，观察消失与半透明显示两种状态。截取这个练习目录，并说明 Windows 的 AppData 用来放应用数据、Git 的 .git 用来存历史，以及排查项目配置时何时需要看见隐藏项目。只需动自己刚建的目录。

## 任务 167 | 用 7-Zip 压缩与解压
从 7-Zip 官网选与你的系统架构相符的版本，把含 `hello.txt` 和 `hello.html` 的练习目录分别压成 7z 和 ZIP。把 ZIP 复制到新建的 `restore-test` 并在那里解压。打开解出的网页，交两种压缩包的文件名、实际大小及恢复后的网页截图，说说合并文件与压缩体积各有什么用。[7-Zip 官网](https://www.7-zip.org/)

## 任务 1 | 认识编辑器
打开 VS Code，新建空白文本并输入「今天写网页」。再打开浏览器访问一个页面。交编辑器窗口截图和两句自己的说明：你会在哪个窗口改源文件，在哪个窗口看运行效果？[VS Code 下载](https://code.visualstudio.com/download)

## 任务 2 | 创建学习文件夹
打开 `my-first-web`，在左侧创建 `hello.txt`，写学习昵称和一个可检验的小目标，例如「能自己修改标题并刷新」。保存并关闭编辑器，重新打开文件夹验证文字。交一张同时显示文件树与内容的截图。

## 任务 3 | 让浏览器显示一句话
在 `hello.html` 写下本关示例，先打开网页，再把标题改成「你好，我的第一个页面」。交修改前后的标题和浏览器截图，说明保存影响磁盘文件、刷新让浏览器重新读取。

## 任务 4 | 找回并修改自己的文件
关闭编辑器窗口，再从练习目录重新找到 `hello.html`。在标题下一行加 `<p>这是我的第一个网页。</p>`。交文件名和刷新后同时显示标题、段落的页面，解释浏览器通常怎样对待 .txt 和 .html。

## 任务 5 | 认识调试工具
在浏览器里右键标题，选择「检查」，在「元素」面板双击标题中的文字改成「临时标题」。截图，再刷新页面并记下刷新后的标题。打开编辑器核对磁盘文件，说明要永久保留内容应该改哪一处。
