# 把第一条看板数据通过 HTTP 发给浏览器
你的 `task-board/todo-app` 是页面。从这一关开始，旁边的 `todo-server` 接受浏览器请求并运行 Java。先在本机终端执行 `java -version` 和 `javac -version`，两者都应可运行。本课程使用 JDK 17 和 Spring Boot 3.x，用免费 JDK 和编辑器即可。[Spring Boot 3.5 环境要求](https://docs.spring.io/spring-boot/3.5/system-requirements.html)

在 Spring Initializr 选择 Maven、Java、Jar 和 Spring Web。Group 填 `com.example`，Artifact 填 `todo-server`，Package name 明确填 `com.example.todo`，选择 Java 17 与兼容的稳定 3.x。如果生成器已只提供后续大版本，可用生成器生成 Maven 项目取得 `mvnw`、`mvnw.cmd`、`.mvn`，然后把 `pom.xml` 的 Spring Boot 父版本改为 `3.5.16`、`java.version` 设为 `17`，在 dependencies 只保留 3.x 的 `spring-boot-starter-web` 与测试用的 `spring-boot-starter-test`。启动类应位于 `src/main/java/com/example/todo`。[Spring Initializr](https://start.spring.io/) · [Spring 官方接口教程](https://spring.io/guides/gs/rest-service/)

从熟悉的 JS 对象 `{message:"你好"}` 出发。Java 要声明返回值类型，`Map<String, String>` 表示键和值都是字符串。建立 `src/main/java/com/example/todo/controller/HelloController.java`，包名与目录对应。

```java
package com.example.todo.controller;

import java.util.Map;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class HelloController {
    @GetMapping("/hello")
    public Map<String, String> hello() {
        return Map.of("message", "你好");
    }
}
```

在含 `pom.xml` 的目录运行 `.\mvnw.cmd spring-boot:run`（macOS/Linux 为 `./mvnw spring-boot:run`）。首次构建会下载依赖。在浏览器打开 `http://localhost:8080/hello`，观察 JSON，再在 Network 中看状态码和 Content-Type。停止服务后再请求一次，对比「连接失败」与服务运行时访问不存在路径得到的 404。端口冲突时，在 `src/main/resources/application.properties` 写 `server.port=8081` 并相应更改访问地址。

合上教程，自己新建 `/board-name` 请求并返回看板名。若 `/hello` 返回 404，先看端口，再核对控制器在启动类所在包的下级。修改 Java 后重新运行服务，刷新网页只会重发请求。

## 任务 47 | 跑起第一个 Spring Boot 应用
在项目根目录运行 Wrapper 的 `spring-boot:run` 或使用 IDE 运行带 `@SpringBootApplication` 的类。等待日志出现监听端口以及 Started 行。尚未写根路径时，访问根地址得到 404 也说明服务回应了。交启动日志和一次 HTTP 响应状态，指出自己使用的端口。

## 任务 48 | 编写第一个 GET 接口
先把示例方法改成 `public String hello() { return "你好，世界"; }`。重启后访问 `/hello`；再访问 `/hello-missing` 对比路由匹配。交类的包名、方法注解及成功返回的文字，确认响应来自本机 Java 服务。

## 任务 49 | 理解 JSON 与接口概念
把 `/hello` 换回返回 Map 的版本，检查响应正文有 `message` 字段、类型为 JSON。结合看板用自己的话解释 JSON 表示数据、GET 读取、POST 提交，以及用资源路径配合 HTTP 方法表达操作。例如未来可 GET 任务集合，也可向同一集合 POST 新任务。交响应截图与自己的三个概念说明。

## 任务 158 | 认识 pom.xml 与 Maven 依赖管理
