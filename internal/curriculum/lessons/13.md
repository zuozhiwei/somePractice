# 让树洞从接口读帖子

这一关给原来的树洞页面加一个提供数据的 Java 程序。`web/` 里的 HTML、CSS、JavaScript 负责画界面。`server/` 负责接收请求和提供帖子。先用一条合成帖子把两边约定清楚，第 15 关再换成数据库。

### 准备JDK

- **终端**是用文字执行命令的窗口。在 VS Code 先选「文件 → 打开文件夹」，打开已经包含 `web/` 的 `campus-treehole`，再选「终端 → 新建终端」。看到提示符后输入一行并回车。`cd` 用于进入目录，`pwd` 显示当前位置。命令前的提示符由终端显示，复制时只取命令。
- **Java** 是本章写后端用的语言。**JDK** 是开发工具包，包含运行程序的 `java` 和把源码转成可运行程序的 `javac`。本项目用第 17 版。

先在终端输入 `javac -version`，按回车。如果已经显示 `javac 17` 开头的版本，直接去下面核对两条命令。提示找不到命令时，再做安装步骤。

打开 [Temurin 官方下载页](https://adoptium.net/temurin/releases/?version=17)。版本选 **17 — LTS**（长期支持版），包类型选 **JDK**。用[第一次查到的电脑型号](/level/1?task=166)确认处理器架构。

:::windows

Windows x64 选后缀为 `.msi` 的安装包。双击后依次点 **Next**、接受许可，再进入 **Custom Setup**。保留加入 **PATH** 的选项，再点 **Set JAVA_HOME** 左边的小图标，选择安装到本地磁盘。依次点 **Next → Install → Finish**。PATH 让终端找到命令，JAVA_HOME 让构建工具找到这个 JDK。若下载页没有与你设备匹配的安装包，可以用教师提供的 JDK 17 练习环境。[Temurin 安装说明](https://adoptium.net/installation/windows/)

:::

:::mac

Apple 芯片选 **aarch64**，Intel 选 **x64**，安装包选 `.pkg`。在 Finder 的「下载」里双击安装包。点「继续」，阅读并同意许可后点「安装」。按系统提示授权，看到「安装成功」后点「关闭」。[Temurin 的 Mac 安装说明](https://adoptium.net/installation/macOS/)

:::

:::linux

机房电脑可用教师已经配好的 JDK 17 环境。在自己有管理权限的电脑上，按发行版选择 Temurin 官方安装说明，安装时选第 17 版的 JDK。[Temurin 的 Linux 安装说明](https://adoptium.net/installation/linux)

:::

保存编辑过的文件，退出并重新打开 VS Code，回到原来的 `campus-treehole`。点「终端 → 新建终端」。逐行输入下面两条命令，每次按回车，看到结果再输入下一条。

```text
java -version
javac -version
```

第一行输出里找 `17.`，第二行应以 `javac 17` 开头。小数点后面的数字可以不同。如果只有 `java` 能运行，先确认安装的是 **JDK**。

:::windows

装完仍提示找不到命令时，重新打开安装包，选 **Change**，核对刚才的 PATH 选项。安装程序退出后重新打开 VS Code 再试。

:::

:::mac

已装多个版本时，在本次启动后端的终端依次执行以下两行，再检查版本。

```bash
export JAVA_HOME=$(/usr/libexec/java_home -v 17)
export PATH="$JAVA_HOME/bin:$PATH"
```

:::

- **Spring Boot** 提供 Web 请求处理和内置服务器。**Maven** 根据 `pom.xml` 获取项目依赖、编译和测试。**Maven Wrapper** 是生成在项目里的 `mvnw` 与 `mvnw.cmd`，会为该项目准备对应 Maven。
- **端口**是同一台电脑上用于区分服务的编号。`localhost:8080` 中 `localhost` 指当前电脑，`8080` 是本章的后端端口。**API** 是两段程序请求数据的约定。`GET /api/posts` 表示用 HTTP 的读取方法 GET 向后端询问帖子列表。**JSON** 是浏览器和后端都能读的文本数据格式。`[]` 包住数组，`{}` 包住对象，`"title"` 是字段名。

### 第一份接口文件

完成「在原项目加入树洞后端」后，打开 `server/src/main/java/edu/campus/treehole/PostController.java`。Spring Boot 的启动类也应在 `edu.campus.treehole` 包里。`package` 是 Java 类的归类路径，文件夹与它逐段对应。把下面的完整文件保存进去。

```java
package edu.campus.treehole;

import java.util.List;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
@RequestMapping("/api/posts")
public class PostController {
    @GetMapping
    public List<PostView> list() {
        return List.of(new PostView(
            "demo-1", "晚自习后还想散会儿步", "操场哪片路灯最亮？",
            "DAILY", "2026-11-20T10:20:00Z"));
    }

    public record PostView(String id, String title, String body,
                           String category, String createdAt) {}
}
```

`@RestController` 把返回值转换成 HTTP 正文，`@RequestMapping` 定路径，`@GetMapping` 指定 GET。`record` 把几个字段组合成一条固定形状的数据。最后的 `Z` 代表 UTC。示例中的 UTC 10:20 在中国标准时间显示为当天 18:20。先修改标题并重启核对变化，确认数据确实来自自己的 Java 文件。

[Spring Boot 3.5 的 Java 要求](https://docs.spring.io/spring-boot/3.5/system-requirements.html)

## 任务 46 | 在原项目加入树洞后端

### 操作步骤

在 VS Code 打开 [上一阶段交付的仓库](/level/12?task=45)，展开左侧的 `web/` 确认能看到 `index.html`。先按 [本关参考资料「准备JDK」](/level/13?guide=1#准备JDK) 核对 Java。解压完成后用原来的项目窗口继续。

1. 浏览器打开 [Spring Initializr](https://start.spring.io/)。选择 Maven、Java、3.5 系列中可选的正式版本、Jar、Java 17。Group 填 `edu.campus`，Artifact 与 Name 填 `treehole`，Package Name 核对为 `edu.campus.treehole`。
2. 点 Add Dependencies，搜索并选择 **Spring Web**。点 Generate 下载 ZIP。按[第一关的解压步骤](/level/1?task=4)先解压到下载目录，将解压得到的项目文件夹改名为 `server`，移动到已有 `web` 同级。若版本下拉框只有更新系列，仍然生成 Maven 和 Java 项目来取得 Maven Wrapper。优先选 Java 17。如果表单要求更高的版本，先选择它接受的 Java 版本，解压后按下方替换文件，自己的运行环境仍使用 JDK 17。
3. 回到 VS Code，确认 `server/pom.xml`、`server/mvnw`、`server/mvnw.cmd`、`server/src/` 和原来的 `web/index.html` 都能看到。若变成 `server/treehole/pom.xml`，把内层的文件移到 `server`。

4. 如果生成的 Spring Boot 不是 3.5 系列，把整份 `server/pom.xml` 替换成下方内容，保留 `.mvn/` 与两个 Wrapper 文件。

```xml
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 https://maven.apache.org/xsd/maven-4.0.0.xsd">
    <modelVersion>4.0.0</modelVersion>
    <parent>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-parent</artifactId>
        <version>3.5.16</version>
        <relativePath/>
    </parent>
    <groupId>edu.campus</groupId>
    <artifactId>treehole</artifactId>
    <version>0.0.1-SNAPSHOT</version>
    <properties><java.version>17</java.version></properties>
    <dependencies>
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-web</artifactId>
        </dependency>
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-test</artifactId>
            <scope>test</scope>
        </dependency>
    </dependencies>
    <build>
        <plugins>
            <plugin>
                <groupId>org.springframework.boot</groupId>
                <artifactId>spring-boot-maven-plugin</artifactId>
            </plugin>
        </plugins>
    </build>
</project>
```

若生成器没有提供启动类，在 `server/src/main/java/edu/campus/treehole/TreeholeApplication.java` 保存以下文件。这段代码也可用于替换同名的生成代码。

```java
package edu.campus.treehole;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication
public class TreeholeApplication {
    public static void main(String[] args) {
        SpringApplication.run(TreeholeApplication.class, args);
    }
}
```

### 验收与排查

在资源管理器展开 `server`，同时看到 `pom.xml` 和 `src/main/java` 才能进入启动任务。如果提示用更高的 Java 版本编译，回本任务第 4 步替换 `pom.xml`，再确认终端显示 Java 17。

## 任务 47 | 运行树洞后端

### 操作步骤

在 [创建后端](/level/13?task=46) 后做。打开 VS Code「终端 → 新建终端」，用 `pwd` 查看当前目录。以下命令在含 `web/` 与 `server/` 的根目录开始。

在项目根目录终端执行 `cd server`，再启动后端。

:::windows

```powershell
.\mvnw.cmd spring-boot:run
```

:::

:::mac linux

```bash
./mvnw spring-boot:run
```

若提示 `Permission denied`，在同一目录执行 `chmod +x mvnw`，再运行启动命令。

:::

1. 首次启动会下载依赖，等终端出现 `Tomcat started on port 8080` 和 `Started TreeholeApplication`。保留这个窗口，打开浏览器访问 `http://localhost:8080/api/posts`。还没完成「返回真实的帖子 JSON 结构」时，看到 404 也说明已经连上后端。
2. 在终端按 Ctrl+C 停止程序，再执行相同的启动命令。若 8080 被占用，先找到自己此前启动的后端终端并停止。必须换端口时在 `server/src/main/resources/application.properties` 写 `server.port=8082`，后续浏览器和代理都用该端口。

### 验收与排查

至少两次看到 `Started TreeholeApplication`，且地址端口和日志相同。浏览器提示连接被拒绝时，先回终端找是否已进 `server/`、进程是否一直保持运行。启动窗口不输入浏览器地址。

### 提交

平台对应的实际命令和两条启动日志。

## 任务 49 | 对照网页与 JSON

### 操作步骤

用 [第一次接口 JSON](/level/13?task=48) 的一条响应临时试已有页面。把原始 `state.posts` 备份一份，保持同一文件的 `renderPosts`。

1. 同时打开第 4 关 `web/` 的帖子范例和浏览器中的后端 JSON。把五个字段抄进一张对照表，第一列写 JSON 名，第二列写页面位置。`id` 在打开详情时使用，`title/body` 显示文字，`category` 对应话题标签，`createdAt` 决定时间。
2. 复制一条响应对象到 `web/app.js` 的 `state.posts` 暂时预览。现有列表读取 `post.comments.length`，所以在这条本地示例对象的结尾补 `"comments": []`。保持服务响应的五个字段。把渲染时间处的值传给 `new Date(post.createdAt)`，再调用 `toLocaleString('zh-CN')` 验证显示。恢复原前端合成数据后继续，真正接线在第 17 关。
3. 若出现 `Invalid Date`，核对 `createdAt` 的拼写和完整时间字符串。`id` 用作身份标识，后续按字符串比较。

### 验收与排查

时间、正文及标题能在列表相应位置显示。若 Console 指向 `post.comments.length`，在替换的临时示例对象加 `comments: []`，并确认未改后端公开字段。

### 提交

字段对照和浏览器最终呈现。
