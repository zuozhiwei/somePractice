# 把内存里的待办保存到 MySQL

沿用上一关的 `todo-server`。在项目根目录先用 `./mvnw -v` 确认 Maven 使用 Java 17（Windows 用 `.\mvnw.cmd`）。连接自己的练习库，执行 `USE todo_db; SHOW CREATE TABLE task;`，记下 id、title、done、created_at 的真实列定义。先插入一条易识别的测试数据，稍后比较 SQL 和 HTTP 两个视角的结果。

1. 在 `pom.xml` 的 dependencies 内加入 `org.springframework.boot:spring-boot-starter-data-jpa` 和运行时依赖 `com.mysql:mysql-connector-j`。Spring Boot 父 POM 管理版本。把以下配置加入 `src/main/resources/application.properties`，在启动应用的终端设置 DB_USER 和 DB_PASSWORD。

~~~properties
spring.datasource.url=jdbc:mysql://localhost:3306/todo_db
spring.datasource.username=${DB_USER}
spring.datasource.password=${DB_PASSWORD}
spring.jpa.hibernate.ddl-auto=validate
spring.jpa.open-in-view=false
~~~

2. 在启动类所在包 `com.example.todo` 下创建 `entity/Task.java` 和 `repository/TaskRepository.java`。实体使用 `jakarta.persistence` 的注解。下面是字段映射骨架，请用 IDE 生成四个 getter，以及 title、done 的 setter。无参构造器供 JPA 创建对象；如果添加别的构造器，仍须保留它。

~~~java
@Entity
@Table(name = "task")
public class Task {
    @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    @Column(nullable = false, length = 200)
    private String title;
    @Column(nullable = false, columnDefinition = "TINYINT")
    private boolean done;
    @Column(name = "created_at", nullable = false)
    private LocalDateTime createdAt;

    protected Task() {}
    public Task(String title, boolean done) {
        this.title = title;
        this.done = done;
    }
    @PrePersist
    void stamp() { if (createdAt == null) createdAt = LocalDateTime.now(); }
}
~~~

3. 让 `TaskRepository extends JpaRepository<Task, Long>`。在已有控制器构造器中接收仓库。GET 方法返回 `repository.findAll()`。新建输入类型 `record TaskInput(String title, boolean done) {}`；POST 方法接收 `@RequestBody TaskInput input`，检查标题后执行 `repository.save(new Task(input.title().strip(), input.done()))` 并返回新对象。客户端无需提供 id 或创建时间。

仓库接口放在 `com.example.todo.repository` 包中，导入 `com.example.todo.entity.Task` 和 `org.springframework.data.jpa.repository.JpaRepository`。控制器保留原来的 `/api/tasks` 映射，替换内存列表变量和原有的 GET、POST 方法。下面片段位于控制器类中，类名沿用你的文件名。对于空标题，请求将收到 400。

~~~java
private final TaskRepository repository;
public TaskController(TaskRepository repository) { this.repository = repository; }
public record TaskInput(String title, boolean done) {}

@GetMapping
public List<Task> list() { return repository.findAll(); }

@PostMapping
@ResponseStatus(HttpStatus.CREATED)
public Task create(@RequestBody TaskInput input) {
    if (input.title() == null || input.title().isBlank() || input.title().strip().length() > 200) {
        throw new ResponseStatusException(HttpStatus.BAD_REQUEST, "标题应为 1–200 个字符");
    }
    return repository.save(new Task(input.title().strip(), input.done()));
}
~~~

用 IDE 导入 `java.time.LocalDateTime`、`java.util.List`、`org.springframework.http.HttpStatus`、`org.springframework.web.server.ResponseStatusException` 和相应的 Web 注解。
4. 启动应用。在 Postman 向 `http://localhost:8080/api/tasks` POST JSON `{"title":"检查持久化","done":false}`，随后 GET 同地址。依据 POST 返回的 id 到 MySQL 查询该行。若出现 `Not a managed type`，检查实体是否位于启动包之下；若报列类型不匹配，对照 SHOW CREATE TABLE 改映射，保留已有数据。
