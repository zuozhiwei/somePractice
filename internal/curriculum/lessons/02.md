# 给任务看板搭一个可以填写的页面
从这关起在 `task-board` 下新建 `todo-app`，以后一直改这个目录。上关的 `my-first-web` 留作小实验。新建 `index.html`，每次只添一块，保存后回到浏览器刷新。

```html
<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>任务管理器</title>
</head>
<body>
  <h1>今天的任务</h1>
  <p>把今天想完成的事情记下来。</p>
  <p>先试着写下第一项。</p>
  <label for="task-input">任务名称</label>
  <input id="task-input" type="text">
  <button id="add" type="button">添加</button>
  <ul id="tasks"><li>上课</li></ul>
</body>
</html>
```

`title` 对应标签页，`h1` 出现在页面里。点击「任务名称」应把光标移到输入框，这来自 `for` 与 `id` 的对应。当前按钮只负责显示，第 4 关才会响应点击。

先照着加第二项列表，再合上教程独立加第三项。最后把整个目录复制到别处，从副本打开页面，检查图片是否还在。出现破图时核对后缀、文件位置和英文大小写。副本能独立打开，说明你开始掌握了相对路径。

## 任务 6 | 创建并打开第一个 HTML 文件
在 `todo-app/index.html` 写入完整的骨架，正文先放「我的第一个网页」。可手写上面的结构，也可在空的 HTML 文件里输入英文 `!` 并按 Tab 展开。交文件树和浏览器打开的正文截图。

## 任务 7 | 认识 HTML 基本结构
把 `title` 改成「任务管理器」，在 `body` 放一个一级标题和两个内容不同的段落。只修改其中一个段落后刷新，检查标签标题有没有一起变。交包含浏览器标签与页面正文的截图，并标注它们各自来自哪个元素。

## 任务 8 | 添加列表与输入框
在 `ul` 中为「上课、写作业、社团活动」各建一个 `li`。列表前放带可见标签的文本框与「添加」按钮。给文本框试输「读书」，确认三条静态项目仍然在。交缩进后的 HTML 片段与页面画面。

## 任务 9 | 插入图片与超链接
把自己的小图放在 `index.html` 同目录，按实际文件名写 `<img src="map.png" alt="任务看板图标" width="80">`。另加 `<a href="https://www.baidu.com">去百度搜索</a>`。从目录副本打开，分别检查图片和链接，提交相对路径、打开后的图片及链接去向。
