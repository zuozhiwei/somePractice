# 写出首批树洞帖子

### 开始前

先确认第 1 关的网页能在浏览器打开。接着用标签把自己的首页分成列表、详情和写帖区。改动都放在 `web/index.html` 的 body 里面。 [上一步](/level/1?task=4)

### 首页的 HTML 示例

先用上一关做好的网页做一个小实验。在 VS Code 左侧展开 `web`，点 `index.html`。找到 `<p>` 和 `</p>` 之间你写的第一句介绍，改一个字，保存并刷新浏览器，确认改的是原项目。HTML 是写网页内容和结构的语言。尖括号里的名字叫标签，例如 `<p>欢迎来到树洞</p>` 就是一段话。

上一关用 `<h1>` 写大标题，用 `<p>` 写一段文字。这些标签放在 `<body>` 和 `</body>` 之间，那里存放浏览器在页面内显示的内容。[回看网页标签](/level/1?guide=1#认识网页标签)

打开原来的 `campus-treehole/web/index.html`，点 VS Code 的「编辑 → 查找」（Edit → Find），输入 `<body>`，按 Esc 关闭查找框。保留 `<body>` 和 `</body>`，把它们之间的内容换成下面的片段。示例中，`id` 是元素的名字，给每个名字在同一页只用一次。第 4 关的脚本会用这些名字找到对应区域。粘贴后把示例的大标题改回你的产品名。

```html
<header>
  <h1>我的校园树洞</h1>
  <p>分享一段校园日常，或问问大家。</p>
</header>
<main>
  <section aria-labelledby="feed-title">
    <h2 id="feed-title">树洞帖子</h2>
    <div class="post-list" id="post-list">
      <article class="post-card">
        <p>匿名同学 · 校园提问</p>
        <h3>图书馆附近哪里有自习插座？</h3>
        <p>想找一处晚上方便读书的公共空间。</p>
        <time datetime="2026-11-20T18:20:00+08:00">11 月 20 日 18:20</time>
      </article>
    </div>
  </section>
  <section id="post-detail">
    <h2 id="detail-title">示例帖子详情</h2>
    <p id="detail-body">这里稍后会显示点开的帖子正文。</p>
    <h3>评论</h3>
    <ul id="comment-list"><li>示例回复：一层长桌有插座。</li></ul>
    <form id="comment-form">
      <label for="comment-body">写评论</label>
      <textarea id="comment-body" maxlength="500" required></textarea>
      <button type="submit">发送评论</button>
    </form>
    <button type="button" id="detail-back">返回帖子列表</button>
  </section>
  <section>
    <h2>写一条帖子</h2>
    <form id="post-form">
      <label for="post-title">标题</label>
      <input id="post-title" maxlength="100" required>
      <label for="post-category">话题</label>
      <select id="post-category">
        <option value="DAILY">校园日常</option>
        <option value="QUESTION">校园提问</option>
        <option value="HELP">互助求助</option>
      </select>
      <label for="post-body">正文</label>
      <textarea id="post-body" maxlength="1000" required></textarea>
      <button type="submit">发到树洞</button>
    </form>
    <p id="feedback" role="status"></p>
  </section>
</main>
```

保存后刷新，应能看到一条帖子、评论示例和两个表单。复制 `article` 整块两次，改成你自己写的虚构主题，示例仍用「匿名同学」。表单今天只检查外观与输入，脚本将在第 4、5 关接上。标签没对齐时，在 VS Code 对照开始和结束标签，展开左侧行号定位。

## 任务 6 | 首页放入三条示例帖子

前置：[在新目录解压并打开网页](/level/1?task=4)。[查看本关的完整网页片段](/level/2?guide=1)。

### 操作步骤

1. 回 VS Code 打开 `web/index.html`。点「编辑 → 查找」，输入 `<body>`，关闭搜索框。从开始标签的下一行选到结束标签 `</body>` 的上一行，替换为「首页的 HTML 示例」里的完整片段。保留第 1 关改好的产品名。
2. 从「编辑 → 查找」搜索 `class="post-card"`。选中从 `<article class="post-card">` 开始到对应的 `</article>` 为止的一整块，复制。将光标放在原来的 `</article>` 后、新一行 `</div>` 前，粘贴两次。
3. 分别把两个副本里的大标题、正文和话题换成「食堂有新菜」「求借一本参考书」一类的不同合成内容，保留匿名提示。保存，再在原浏览器刷新。
4. 只看到一个帖子时，检查是否误把两块放在原卡片内部。三块 `article` 应该彼此并列，都是 `id="post-list"` 的子项。

### 预期结果

页面能从上到下找到三条不同种类的虚构帖子。

### 提交

交三张卡都出现的首页。

## 任务 7 | 给帖子和时间加语义

前置：[首页放入三条示例帖子](/level/2?task=6)。

### 操作步骤

1. 在 `web/index.html` 搜索 `<time`。先选一张卡，在浏览器对应位置找到它的时间，理解这一行的两部分。尖括号里的 `datetime` 给程序读，两个 time 标签之间的文字给人看。
2. 例如活动发生在中国时间 2026 年 11 月 21 日 19:00，可以用 `<time datetime="2026-11-21T19:00:00+08:00">11 月 21 日 19:00</time>`。给自己的合成帖改成另一个日期，两段一起改。
3. 保存刷新，检查卡片中显示自己的可读时间。再去源码检查 `datetime` 的英文双引号和时区。若浏览器原样显示标签，应回 VS Code 检查打开的文件后缀及 HTML 是否复制到了正确位置。

### 预期结果

页面显示人能读的日期，源码里同时有完整的日期、时刻和时区。

### 提交

交一张卡的代码与页面中对应时间。

## 任务 8 | 准备发帖和回帖表单

前置：[给帖子和时间加语义](/level/2?task=7)。[对照本关的两段表单](/level/2?guide=1)。

### 操作步骤

1. 在「首页的 HTML 示例」找到 `id="post-form"` 与 `id="comment-form"` 两段。在自己的 `index.html` 从搜索框定位，用示例片段核对。每个 `label for="字段名"` 都要有一个同名的 `id="字段名"`。例如 `for="post-title"` 对应标题输入。
2. 保存刷新，在网页中点击「标题」文字，再输入「练习标题」。点击「写评论」文字，再输入「练习评论」。这一步还在搭外观，等第 4、5 关再接发送功能，可用刷新清除演示输入。
3. 如果点标签没出现光标，在 HTML 中逐字比对 for 和 id，排查全角引号、额外空格、重复的 id。保存后再点一次。

### 预期结果

两个表单都能输入，标签的 for 与输入框 id 完全一样。

### 提交

交两个表单及点击标签后的一个结果。

## 任务 9 | 准备有来源的补充素材

前置：[准备发帖和回帖表单](/level/2?task=8)。

### 操作步骤

1. 准备一张自己拍摄、制作或获准使用的练习图片。回文件管理器，进入 `campus-treehole/web`，新建 `images`。把图片复制进去。将文件改一个易打字的名字，例如 `campus.jpg`，并保留原始扩展名。
2. 在第一张 `article` 的标题下方插入 `<img src="./images/campus.jpg" alt="傍晚的操场">`。若实际文件是 PNG，就换成完整的真实文件名。再在相邻一行加入 `<a href="https://www.example.org/">查看补充资料</a>`，替换为你实际要分享的资料地址。
3. 保存并刷新，确认图片能看到，点击文字能打开期望的网页。图片显示不出来时对照文件目录、大小写和完整后缀。把图片暂时移出再刷新，也可以看见 alt 文字，验证替代说明有效。

### 预期结果

图能加载，图片名称大小写匹配，点链接能到达预期页面。

### 提交

交页面、素材来源和链接打开结果。
