# 登录后仍然匿名发言

**认证**回答「你是谁」。**会话**是服务器在登录后保存的一段身份状态。浏览器收到的 **Cookie** 如 `JSESSIONID` 是一小段标识，之后请求同一来源时自动带上它。`HttpOnly` 让页面脚本无法读取这个标识。**CSRF** 指第三方页面诱导浏览器带着会话发起写操作。Spring 要求写请求额外提交本网站取得的令牌，以区分两个动作。

### 会话安全配置

将第 19 关单独添加的 crypto 依赖替换为 `org.springframework.boot:spring-boot-starter-security`，其中已包含密码工具。创建 `SecurityConfig.java`，与启动类放在同一包里。下方配置只开放账号入口与帖子读取，要求其他请求登录。第 21 关继续核对授权、退出与浏览器体验。

```java
package edu.campus.treehole;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.http.HttpMethod;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.core.userdetails.User;
import org.springframework.security.core.userdetails.UserDetailsService;
import org.springframework.security.core.userdetails.UsernameNotFoundException;
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;
import org.springframework.security.crypto.password.PasswordEncoder;
import org.springframework.security.web.SecurityFilterChain;

@Configuration
public class SecurityConfig {
    @Bean
    PasswordEncoder passwordEncoder() {
        return new BCryptPasswordEncoder();
    }

    @Bean
    UserDetailsService accountLookup(UserRepository users) {
        return username -> users.findByUsername(username.trim().toLowerCase(java.util.Locale.ROOT))
            .map(account -> User.withUsername(account.username)
                .password(account.passwordHash).roles("MEMBER").build())
            .orElseThrow(() -> new UsernameNotFoundException("账号不存在"));
    }

    @Bean
    SecurityFilterChain security(HttpSecurity http) throws Exception {
        return http
            .authorizeHttpRequests(routes -> routes
                .requestMatchers(HttpMethod.GET, "/api/auth/csrf", "/api/auth/me",
                    "/api/posts", "/api/posts/*", "/api/posts/*/comments").permitAll()
                .requestMatchers(HttpMethod.POST, "/api/auth/register", "/api/auth/login").permitAll()
                .anyRequest().authenticated())
            .formLogin(login -> login.loginProcessingUrl("/api/auth/login")
                .successHandler((request, response, auth) -> response.setStatus(204))
                .failureHandler((request, response, error) -> response.setStatus(401)))
            .exceptionHandling(errors -> errors
                .authenticationEntryPoint((request, response, error) -> response.setStatus(401))
                .accessDeniedHandler((request, response, error) -> response.setStatus(403)))
            .logout(logout -> logout.logoutUrl("/api/auth/logout")
                .logoutSuccessHandler((request, response, auth) -> response.setStatus(204)))
            .build();
    }
}
```

在 `AuthController.java` 增加 `import java.security.Principal;` 与 `import org.springframework.security.web.csrf.CsrfToken;`，再把下面两个方法放入类内。`Principal` 是 Spring 核实过的请求身份。

```java
@GetMapping("/csrf")
public ResponseEntity<Map<String, String>> csrf(CsrfToken csrf) {
    return ResponseEntity.ok().header("Cache-Control", "no-store")
        .body(Map.of("headerName", csrf.getHeaderName(), "token", csrf.getToken()));
}

@GetMapping("/me")
public ResponseEntity<Map<String, Boolean>> me(Principal principal) {
    return ResponseEntity.ok().header("Cache-Control", "no-store")
        .body(Map.of("signedIn", principal != null));
}
```

从网页登录的请求正文使用 `URLSearchParams`，其中用户名字段叫 `username`。先读取 CSRF 对象，并按照它的 `headerName` 发送。登录或退出后重新读取一次令牌。浏览器每次写入前也可以获取新令牌来简化首版逻辑。`AuthController` 的注册同样需要带 CSRF。

[Spring Security 6.5 的 CSRF 说明](https://docs.spring.io/spring-security/reference/6.5/servlet/exploits/csrf.html)

### 浏览器登录函数

保存为 `web/auth.js`。调用现有 [共用请求函数](/level/17?task=64) 获取服务器认可的请求令牌。`URLSearchParams` 把两个输入值编码成登录表单发送。服务返回状态 204 时没有正文，随后从 `/auth/me` 读当前会话。

```js
import { api } from './api.js'

export async function signIn(username, password) {
  const csrf = await api('/auth/csrf')
  const response = await fetch('/api/auth/login', {
    method: 'POST',
    headers: { [csrf.headerName]: csrf.token },
    body: new URLSearchParams({ username, password })
  })
  if (!response.ok) {
    const error = new Error(response.status === 401
      ? '用户名或密码不正确' : '登录暂不可用，请重试')
    error.status = response.status
    throw error
  }
  return api('/auth/me')
}
```

### 登录练习页

保存为 `web/dev-auth.html`。将浏览器地址改为 `http://localhost:5173/dev-auth.html`。这个页面是本课的测试工具，接入正式账号区前移除。

```html
<!doctype html>
<html lang="zh-CN">
  <head><meta charset="utf-8"><title>树洞本机登录验收</title></head>
  <body>
    <h1>树洞本机登录验收</h1>
    <form id="login-probe">
      <label>用户名 <input name="username" autocomplete="username" required></label>
      <label>密码 <input name="password" type="password" autocomplete="current-password" required></label>
      <button type="submit">尝试登录</button>
      <button id="without-token" type="button">核对缺少令牌</button>
      <button id="logout-probe" type="button">退出练习会话</button>
    </form>
    <p id="probe-result" role="status"></p>
    <script type="module">
      import { signIn } from './auth.js'
      import { api } from './api.js'
      const form = document.querySelector('#login-probe')
      const result = document.querySelector('#probe-result')
      async function showState() {
        const { signedIn } = await api('/auth/me')
        result.textContent = 'signedIn=' + signedIn
      }
      form.addEventListener('submit', async event => {
        event.preventDefault()
        const fields = new FormData(form)
        try {
          await signIn(fields.get('username'), fields.get('password'))
          await showState()
        } catch (error) {
          result.textContent = (error.status || '连接失败') + ' ' + error.message
        }
      })
      document.querySelector('#without-token').addEventListener('click', async () => {
        if (!form.reportValidity()) return
        const response = await fetch('/api/auth/login', {
          method: 'POST',
          body: new URLSearchParams(new FormData(form))
        })
        result.textContent = 'HTTP ' + response.status
      })
      document.querySelector('#logout-probe').addEventListener('click', async () => {
        const csrf = await api('/auth/csrf')
        await api('/auth/logout', { method: 'POST', headers: { [csrf.headerName]: csrf.token } })
        await showState()
      })
      showState().catch(error => { result.textContent = error.message })
    </script>
  </body>
</html>
```
