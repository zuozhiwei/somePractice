# 用本地签名服务签发限时登录凭证

沿用注册接口、账户仓库与 BCrypt 编码器。在 `todo-server/pom.xml` 为 `io.jsonwebtoken` 加三项相同版本 `0.12.6` 的依赖：编译期 `jjwt-api`，运行期 `jjwt-impl` 和 `jjwt-jackson`。配置文件写 `jwt.secret=${JWT_SECRET}` 和 `jwt.expiration=3600000`。在本机生成 32 个随机字节并转换为 Base64，交给本地启动环境，例如在 JShell 执行 `var k = new byte[32]; new java.security.SecureRandom().nextBytes(k);` 后用 `java.util.Base64.getEncoder().encodeToString(k)` 取值。此值只供本地服务持有。

1. 创建 `security/TokenService.java`，使用构造器从 Spring 读取配置，解码 Base64 为 HMAC 密钥。下面是类中的核心代码；导入 io.jsonwebtoken.Jwts、io.jsonwebtoken.security.Keys、javax.crypto.SecretKey、java.time.Instant、java.util.Date/Base64 及 Spring 的 Value。类加 `@Service`。

~~~java
private final SecretKey key;
private final long ttl;

public TokenService(@Value("${jwt.secret}") String encoded,
                    @Value("${jwt.expiration}") long ttl) {
    this.key = Keys.hmacShaKeyFor(Base64.getDecoder().decode(encoded));
    this.ttl = ttl;
}
public String issue(long id, String username) {
    Instant now = Instant.now();
    return Jwts.builder().issuer("todo-server")
        .subject(Long.toString(id)).claim("username", username)
        .issuedAt(Date.from(now)).expiration(Date.from(now.plusMillis(ttl)))
        .signWith(key, Jwts.SIG.HS256).compact();
}
~~~

2. 在 POST /api/auth/login 读取用户名与密码。按用户名查询用户，调用 `encoder.matches(输入密码, 库中散列)`。只有匹配才签发 token，回复 `{"token":"…","username":"…"}`。用户名不存在与密码不对统一回复 HTTP 401「用户名或密码错误」，缺必填项回复 400。请求日志和错误日志都略去密码、令牌。
3. 在本机查看自己练习 token 的前两段。点号分隔的 header 和 payload 可通过 Base64URL 解码；第三段签名由服务器校验。把 `exp - iat` 换算为分钟，应与 ttl 配置一致。重新启动后不能验证先前 token 时，检查密钥是否被重新随机生成。签发和验证的具体调用方式见 [JJWT 0.12.6 说明](https://github.com/jwtk/jjwt/blob/0.12.6/README.adoc)。
