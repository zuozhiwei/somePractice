# 用一轮故障演练把看板打磨成可交付的软件
这一关用另一份本地练习数据做故障演练。先导出正常 JSON，把源代码复制一份备用。按「数据与存储、渲染、事件」重排 `script.js`，用一个统一的加载入口。以下代码复用前一关的 `readTaskList`；HTML 中放 `<p id="notice" role="status"></p>`，用来说明异常。脚本仍在 body 末尾执行。

```js
function loadTasks() {
  try {
    const raw = localStorage.getItem("tasks");
    if (raw === null) return [];
    if (!Array.isArray(JSON.parse(raw))) throw new Error("需要任务数组");
    return readTaskList(raw);
  } catch (error) {
    document.getElementById("notice").textContent =
      "任务数据暂时无法读取，可以从之前导出的 JSON 恢复。";
    return [];
  }
}
```

写入失败也可能发生。让 `saveTasks` 捕获存储失败，显示「本次变更尚未保存」，不要给出「保存成功」。先模拟无数据、坏 JSON、合法但结构错误的对象，再用备份还原正确的数组。不要清空整个浏览器的存储。

给按钮、输入框和选中的行添加清楚的焦点样式。用 Tab 独立走完添加、编辑、完成三步，按 Delete 仅在列表行获得焦点时删除；编辑文字时应正常删除光标旁字符。自己增加一条针对输入法的测试：中文候选尚未确定时按回车，不应提前添加任务。
