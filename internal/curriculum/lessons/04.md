# 打开详情并写一条评论

### 详情和评论的 JavaScript 示例

**JavaScript** 是让网页响应操作的语言。你已经有了「发送评论」按钮，这一关要让它在点击后把文字加进当前帖子。浏览器按从上到下的顺序读取写在 `.js` 文件里的指令，这样的文件叫脚本。

先确认浏览器能找到脚本。在 VS Code 左侧右键 `web` 并新建 `app.js`，在第一行写 `console.log("树洞启动了");`。接着按下段说明给 HTML 加上 `script` 标签，保存两个文件，打开页面。右键网页空白处选「检查 → 控制台（Console）」，刷新后应看到「树洞启动了」。若没有，先核对两个文件在同一文件夹、文件名是 `app.js`，再继续。确认后用下面的完整示例替换这一行。

示例中的 `posts` 是帖子**数组**，也就是一个有顺序的列表。方括号里的三个大括号各代表一条帖子，`title` 是它的一项数据。以 `function` 开头的是**函数**，把一组动作起名后就能重复使用。读第一遍时，先找到三处帖子标题，选一条换成自己的文字，看它会在网页哪里出现。

打开同一份 `index.html`，在 `</head>` 前加入 `<script defer src="./app.js"></script>`。`defer` 会等待页面元素准备好，再运行脚本。用脚本替换静态帖子，不需要手动删除第 2 关写的卡片。把数组里的示例文字改成你自己的三条合成帖子。

```js
const categoryLabels = { DAILY: "校园日常", QUESTION: "校园提问", HELP: "互助求助" };
const state = {
  posts: [
    { id: "demo-1", title: "哪里有自习插座？", body: "想找公共自习空间。",
      category: "QUESTION", createdAt: "2026-11-20T18:20:00+08:00", comments: [] },
    { id: "demo-2", title: "散步遇到一只橘猫", body: "操场转角见到它。",
      category: "DAILY", createdAt: "2026-11-20T18:40:00+08:00", comments: [] },
    { id: "demo-3", title: "求一本二手书", body: "想借一本课程参考书。",
      category: "HELP", createdAt: "2026-11-20T19:00:00+08:00", comments: [] },
  ],
  draft: null,
};
let activePostId = null;
const $ = (selector) => document.querySelector(selector);

function addText(parent, tag, text) {
  const node = document.createElement(tag);
  node.textContent = text;
  parent.append(node);
  return node;
}

function renderPosts(posts = state.posts) {
  const list = $("#post-list");
  list.replaceChildren();
  if (!posts.length) addText(list, "p", "这里还没有帖子。");
  for (const post of posts) {
    const card = document.createElement("article");
    card.className = "post-card";
    addText(card, "p", "匿名同学 · " + categoryLabels[post.category]);
    addText(card, "h3", post.title);
    addText(card, "p", post.body);
    addText(card, "p", `${new Date(post.createdAt).toLocaleString()} · ${post.comments.length} 条评论`);
    const button = addText(card, "button", "打开详情");
    button.type = "button";
    button.addEventListener("click", () => showPost(post.id));
    list.append(card);
  }
}

function showPost(id) {
  const post = state.posts.find((item) => item.id === id);
  if (!post) return;
  activePostId = id;
  $("#post-detail").hidden = false;
  $("#detail-title").textContent = post.title;
  $("#detail-body").textContent = post.body;
  const list = $("#comment-list");
  list.replaceChildren();
  if (!post.comments.length) addText(list, "li", "还没有评论。");
  for (const comment of post.comments) addText(list, "li", "匿名同学：" + comment.body);
}

function nextId() {
  return String(Date.now()) + "-" + Math.random().toString(36).slice(2);
}

// 第 7 关会把更改保存到浏览器。
function saveData() {}

$("#detail-back").addEventListener("click", () => {
  activePostId = null;
  $("#post-detail").hidden = true;
  $("#feed-title").scrollIntoView();
});

$("#comment-form").addEventListener("submit", (event) => {
  event.preventDefault();
  const post = state.posts.find((item) => item.id === activePostId);
  const body = $("#comment-body").value.trim();
  if (!post || !body || body.length > 500) {
    $("#feedback").textContent = "请写 1 到 500 个字再发送。";
    return;
  }
  post.comments.push({ id: nextId(), body, createdAt: new Date().toISOString() });
  event.target.reset();
  $("#feedback").textContent = "评论已发送。";
  saveData();
  showPost(post.id);
  renderPosts();
});

$("#post-detail").hidden = true;
renderPosts();
```

保存两个文件并刷新。点第一条的「打开详情」，在下方评论框写一句合成回复，点发送。详情出现回复，列表显示「1 条评论」。第二条没有变化。若按钮没有反应，右键网页选「检查」，打开 Console，点击第一条红字进入具体文件和行号。反复提示 `null` 时，检查第 2 关 HTML 的 id 是否与脚本拼写一致。若想保留上一关的自制图片，可给一条示例记录加 `imageSrc` 与 `imageAlt`，在创建卡片时写入 `img` 的 src、alt 再插入，文字仍用 textContent。

## 任务 14 | 接入树洞脚本

前置：[适配两个窗口宽度](/level/3?task=13)。[查看完整 JavaScript 范例](/level/4?guide=1)。

### 操作步骤

1. 在 VS Code 左侧右键 `web`，建 `app.js`。复制「详情和评论的 JavaScript 示例」里的完整脚本并保存。回 `index.html` 搜索 `</head>`，在它上一行加 `<script defer src="./app.js"></script>`。
2. 打开原网页刷新。为了确认脚本启动，可在 `app.js` 第一行临时加 `console.log("树洞启动");` 后保存。网页空白处右键「检查」，点「控制台 / Console」查看结果。
3. 控制台无启动文字时刷新一次。出现 404 或找不到文件时检查两个源文件是否同一层。出现 `null` 时读错误给出的行号，核对第 2 关的页面 id。

## 任务 15 | 按 ID 打开帖子详情

前置：[接入树洞脚本](/level/4?task=14)。

### 操作步骤

1. 在浏览器找到第一条卡片，读一下它的标题和正文，再点「打开详情」。向下找到详情区，确认标题和正文都来自这张卡，而不是其他帖子。
2. 回到列表，点第二张卡上的「打开详情」。再点「返回帖子列表」，观察区块收起。菜单点错时可搜索浏览器上的「打开详情」，每张卡只应有一个。
3. 如果两次详情一样，在 `app.js` 查 `showPost(post.id)` 这一行和数组内的两个 id。每条 id 必须唯一，按钮应传当前条目的 id。

### 预期结果

一个页面可切到不同帖子，返回后仍停在列表。

### 提交

交两次不同详情和返回结果。

## 任务 16 | 更新回帖计数

前置：[按 ID 打开帖子详情](/level/4?task=15)。

### 操作步骤

1. 打开一条从未回过的合成帖，先记住卡片的「0 条评论」和详情中的「还没有评论」。在「写评论」下面输入第一句，发送。
2. 确认评论出现，返回列表看同一张卡是否变为 1 条。再开放相同详情，发第二句，核对变为 2 条，另一张卡仍为 0。
3. 正文已经出现但计数没有更新时，检查 `post.comments.push` 之后有没有调用 `renderPosts()`，保存脚本再重演。当前版本刷新会重置数据。

### 预期结果

同一条帖的计数从 0 变为 1 再变为 2。

### 提交

交有无评论的对比。

## 任务 156 | 调试一次详情切换

前置：[为当前帖子添加回复](/level/4?task=18)。

### 操作步骤

1. 在 Edge 或 Chrome 的网页空白处右键「检查」，从上方点「源代码 / Sources」。若找不到标签，点右侧双箭头展开。左侧文件树展开自己的本地文件，点 `app.js`。
2. 用编辑器或源代码面板搜索 `function showPost(id)`，点击函数里第一个可执行语句左边的行号。出现有颜色的标记就是断点。回网页点第一张卡上的「打开详情」。
3. 浏览器暂停时看「范围 / Scope」中的 `id`，或将鼠标停在代码里的 `id` 上。记下值，再点顶部继续运行按钮。对另一张卡重复一次。一直不暂停时，确认打断点的是浏览器这次实际加载的 app.js。

### 预期结果

每次点击传入对应帖子 ID，继续后详情恢复。

### 提交

交一次暂停位置和你查到的 ID。
