# 从一次点击追到数组里的一条任务
沿用 `todo-app` 的 HTML 与 CSS。确认页面只有一组 `task-input`、`add`、`tasks` 三个 id。在 `</body>` 前加入 `<script src="script.js"></script>`，同目录新建脚本。先只写 `console.log("脚本加载成功")`，看到控制台输出后再往下做。

脚本先取页面元素，再绑定事件。下面是本关第一个可运行的闭环，添加一次只改一次数组，`render` 每次根据整个数组重新画列表。

```js
const input = document.getElementById("task-input");
const list = document.getElementById("tasks");
const tasks = [];

function render() {
  list.replaceChildren();
  for (const text of tasks) {
    const row = document.createElement("li");
    row.textContent = text;
    list.appendChild(row);
  }
}

function addTask() {
  const text = input.value.trim();
  if (!text) return;
  tasks.push(text);
  input.value = "";
  render();
}

document.getElementById("add").addEventListener("click", addTask);
render();
```

先在纸上预测点击两次后的 `tasks.length`，再用断点核对。初次调用 `render()` 会清空上关的静态示例。若控制台提示对 `null` 读取属性，核对 id 拼写以及脚本是否放在页面末尾。成功后自己为列表添一行计数，尝试将一项划掉并恢复；下关会把完成状态也放进数据。
