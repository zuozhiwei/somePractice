# 把添加、完成与删除接成一个可重复测试的作品
继续使用 `todo-app`。先压缩一份第 4 关的目录。试着完成 A 后再添加 B，观察 A 的样式是否消失。原因在于重新建立的 DOM 元素不会记住旧元素的样式。现在让数组的每一项同时保存名字和完成状态。

把 `tasks.push(text)` 改为 `tasks.push({ text, done: false })`，在 HTML 中加入 `<p id="count" aria-live="polite"></p>`。保留原有输入框事件，用下面的函数替换旧 `render`；完成状态的样式可沿用 `.done { color: #545d56; text-decoration: line-through; }`。

```js
function render() {
  list.replaceChildren();
  tasks.forEach((task, index) => {
    const row = document.createElement("li");
    const title = document.createElement("button");
    title.type = "button";
    title.textContent = task.text;
    title.classList.toggle("done", task.done);
    title.setAttribute("aria-pressed", String(task.done));
    title.onclick = () => toggleTask(task);
    const remove = document.createElement("button");
    remove.textContent = "删除";
    remove.onclick = () => {
      tasks.splice(index, 1);
      render();
    };
    row.append(title, remove);
    list.append(row);
  });
  const done = tasks.filter(task => task.done).length;
  document.getElementById("count").textContent = "已完成 " + done + " / 共 " + tasks.length;
}

function toggleTask(task) {
  task.done = !task.done;
  render();
}
```

例子里按钮上显示原任务名，按空格和点文字都能切换。自己补全空输入的可见提示。测试「读书、读书、跑步」：只把第二项划掉，再删除第一项，留下的「读书」仍应已完成。若页面出现 `[object Object]`，检查显示时是否取了 `task.text`。
