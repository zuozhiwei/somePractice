# 给旧任务升级格式，并保住已有完成记录
第 5 关的版本可能已经用了对象，但早期练习也可能把 `["背单词","散步"]` 存在 `tasks`。新页面要同时认识这两种存档。先在练习看板控制台执行 `localStorage.getItem("tasks")`，把结果另存为本地文本备份。

把标题明确为字符串，把完成标记明确为布尔值。以下函数处理一条旧记录。在 `loadTasks` 解析出数组后，对每一项调用它，再过滤空记录；新任务继续以 `{text, done:false}` 建立。

```js
function normalizeTask(item) {
  if (typeof item === "string") {
    const text = item.trim();
    return text ? { text, done: false } : null;
  }
  if (!item || typeof item.text !== "string" || !item.text.trim()) return null;
  return { ...item, text: item.text.trim(), done: item.done === true };
}

function readTaskList(raw) {
  const rows = JSON.parse(raw || "[]");
  return Array.isArray(rows) ? rows.map(normalizeTask).filter(Boolean) : [];
}
```

先在控制台独立运行 `readTaskList('["旧任务",{"text":"新任务","done":true}]')`，预期两行，只有后一行完成。接回看板后，完成按钮只改这一行的 `done`，通过 `commit()` 写盘并渲染。自己画出三行数据，手算已完成和未完成，再与界面核对。留意字符串 `"false"` 在 JavaScript 中也是真值，直接写 `Boolean(item.done)` 会把它算错。
