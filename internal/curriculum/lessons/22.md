# 帖子和回复的归属留在服务器

**归属**指服务端记录哪位登录成员创建了帖子或评论。记录留在数据库中。通过登录身份取用户 ID，创建时用它填写 `owner_id`，编辑或删除时同时校验资源 ID 与当前用户 ID。

### 迁移作者归属

先用第 19 关注册一个仅供开发的 `learner_a`。在自己的开发库保存第 18 关的合成数据备份后执行 `server/db/04-owners.sql`。下面分三步增加列、给旧合成数据归属、最后加约束。在管理员客户端先选中自己的开发库，执行每个代码段后检查结果。已有其他真实数据时需要按实际归属设计迁移，本课使用自己的合成开发库。

```sql
ALTER TABLE posts ADD COLUMN owner_id BIGINT NULL;
ALTER TABLE comments ADD COLUMN owner_id BIGINT NULL;
SET @owner_id = (SELECT id FROM users WHERE username='learner_a');
SELECT @owner_id;
UPDATE posts SET owner_id=@owner_id WHERE owner_id IS NULL;
UPDATE comments SET owner_id=@owner_id WHERE owner_id IS NULL;
SELECT COUNT(*) FROM posts WHERE owner_id IS NULL;
SELECT COUNT(*) FROM comments WHERE owner_id IS NULL;
```

```sql
ALTER TABLE posts MODIFY owner_id BIGINT NOT NULL,
  ADD CONSTRAINT fk_posts_owner FOREIGN KEY (owner_id) REFERENCES users(id);
ALTER TABLE comments MODIFY owner_id BIGINT NOT NULL,
  ADD CONSTRAINT fk_comments_owner FOREIGN KEY (owner_id) REFERENCES users(id);
```

### 读取当前会员

在 `Post.java` 和 `Comment.java` 加 `@Column(name="owner_id", nullable=false) Long ownerId;`。在两个构造函数尾部加 `Long ownerId` 参数并赋值。新增的 `CurrentUser.java` 只从 Spring 核对的 Principal 查询实际用户 ID。

```java
package edu.campus.treehole;

import java.security.Principal;
import org.springframework.http.HttpStatus;
import org.springframework.stereotype.Service;
import org.springframework.web.server.ResponseStatusException;

@Service
public class CurrentUser {
    private final UserRepository users;

    CurrentUser(UserRepository users) { this.users = users; }

    public Long id(Principal principal) {
        if (principal == null)
            throw new ResponseStatusException(HttpStatus.UNAUTHORIZED, "请先登录");
        return users.findByUsername(principal.getName()).map(account -> account.id)
            .orElseThrow(() -> new ResponseStatusException(HttpStatus.UNAUTHORIZED, "请重新登录"));
    }
}
```

### 只给作者显示编辑入口

在 `PostRepository.java` 加 `List<Post> findAllByOwnerId(Long ownerId);`。新建 `MyPostController.java` 到相同包。这个私有端点只列当前账号拥有的帖子，第 26 关再补新增的治理字段。

```java
package edu.campus.treehole;

import java.security.Principal;
import java.util.List;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class MyPostController {
    private final PostRepository posts;
    private final CurrentUser currentUser;

    MyPostController(PostRepository posts, CurrentUser currentUser) {
        this.posts = posts;
        this.currentUser = currentUser;
    }

    @GetMapping("/api/me/posts")
    public ResponseEntity<List<PostController.PostView>> mine(Principal principal) {
        return ResponseEntity.ok().header("Cache-Control", "no-store").body(
            posts.findAllByOwnerId(currentUser.id(principal)).stream()
                .map(PostController::view).toList());
    }
}
```

在 `web/app.js` 把 `refreshPosts` 与 `showPost` 的 `local: true` 都改成 `local: false`。把 `renderPostDetail` 与原编辑、删除事件判断 `post.local` 的位置换成 `ownedPostIds.has(post.id)`。在 `let signedIn` 后添加 `let ownedPostIds = new Set();`。然后给 `renderAccount` 清空旧持有记录并异步获取这个账号的私有列表。

```js
async function refreshOwnedPosts() {
  const epoch = accountEpoch;
  ownedPostIds = new Set();
  if (signedIn) {
    try {
      const posts = await api("/me/posts");
      if (epoch !== accountEpoch) return;
      ownedPostIds = new Set(posts.map((post) => String(post.id)));
    } catch (error) {
      if (epoch === accountEpoch) $("#account-error").textContent = error.message;
    }
  }
  const ownsActivePost = ownedPostIds.has(activePostId);
  $("#edit-post").hidden = !ownsActivePost;
  $("#delete-post").hidden = !ownsActivePost;
}
```

在 `renderAccount` 末尾、以及 `publishPost` 成功取得保存结果后分别调用 `refreshOwnedPosts()`。刷新成功后自己发的帖子可出现两个按钮。账号切换时立刻把两个按钮设为 hidden，等本次私有读取确认。即使没有按钮，服务端仍对每次 PATCH 和 DELETE 单独检查归属。
