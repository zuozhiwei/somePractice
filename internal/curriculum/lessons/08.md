# 用四个数据操作管住编辑、删除和保存
现在列表既在页面上，也在浏览器存储里。先在练习看板加 A、B、C，刷新确认第 7 关的保存可用。把「改数组、写存储、刷新界面」放进同一个提交点，读取操作保持只读。

保留现有的 `tasks`、`saveTasks` 和 `render`。将添加按钮原来的处理改成读取输入框并调用 `addTask(input.value)`，成功才清空输入。下面函数接收的 index 是原数组位置，从 0 开始。

```js
function commit() {
  saveTasks();
  render();
}
function addTask(text) {
  const title = text.trim();
  if (!title) return false;
  tasks.push({ text: title, done: false });
  commit();
  return true;
}
function updateTask(index, text) {
  if (!tasks[index] || !text.trim()) return false;
  tasks[index].text = text.trim();
  commit();
  return true;
}
function deleteTask(index) {
  if (!tasks[index]) return;
  tasks.splice(index, 1);
  commit();
}
function getTasks() {
  return tasks.map(task => ({ ...task }));
}
```

编辑要经历三个时刻：点「编辑」时用旧标题填充该行临时输入框；打字时保留原数据；回车或按「确定」时调用 `updateTask`。取消时调用 `render()` 丢弃临时输入。若一输入就跳出编辑状态，检查有没有在每个 input 事件都重绘整张列表。
