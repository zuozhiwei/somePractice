# 编辑本地帖子与草稿

### 开始前

先复查第 7 关只刷新一次仍能找回内容。现在同一个发布表单既可以新建帖子，也可以改目前选中的帖子。 [上一步](/level/7?task=28)

### 编辑帖子和清除草稿示例

先加两个按钮。在详情的「返回」旁加入 `<button id="edit-post" type="button" hidden>编辑我的练习帖</button>`。在发表区加 `<button id="clear-draft" type="button">清空本地草稿</button>`。在 `showPost` 更新删除按钮的下一行，加 `$("#edit-post").hidden = !post.local;`。

在 VS Code 打开 `web/app.js`，从「编辑 → 查找」搜索 `let activePostId`，在它的下一行加 `let editingPostId = null;`。这样写在函数外的变量叫全局变量，各个按钮都能读到这次正在编辑的帖子编号。在 `app.js` 末尾加入：

```js
$("#edit-post").addEventListener("click", () => {
  const post = state.posts.find((item) => item.id === activePostId);
  if (!post?.local) return;
  editingPostId = post.id;
  fillPostForm(post);
  $("#post-title").focus();
  $("#feedback").textContent = "正在编辑已有帖子，点发到树洞保存。";
});

$("#clear-draft").addEventListener("click", () => {
  if (!window.confirm("只清空未发布草稿，已发布帖子与回复保留。继续吗？")) return;
  state.draft = null;
  if (editingPostId === null) fillPostForm(null);
  saveData();
  $("#feedback").textContent = "本地草稿已清空。";
});
```

找到 `publishPost` 中的 `const post = …` 和 `state.posts.unshift(post)`，用以下四行替换，保留函数后面的渲染与保存。用 `Object.assign` 修改同一个对象，所以原 ID、评论和创建时间不会被覆盖。

```js
const existing = state.posts.find((item) => item.id === editingPostId && item.local);
const post = existing || { id: nextId(), createdAt: new Date().toISOString(), comments: [], local: true };
Object.assign(post, fields);
if (!existing) state.posts.unshift(post);
editingPostId = null;
```

在同一个函数中，将后续的 `state.draft = null;` 改为 `if (!existing) state.draft = null;`。编辑已有帖子时，这能保留之前没发完的新帖草稿。再把「恢复草稿」按钮的回调换成 `() => { editingPostId = null; fillPostForm(state.draft); }`。在删除函数过滤帖子前加入 `if (editingPostId === post.id) editingPostId = null;`。

先发一帖、评论一次、编辑标题并刷新。若产生两条帖子，暂停在 `publishPost` 查看 `editingPostId`，检查详情的编辑按钮是否调用了编辑分支。

## 任务 31 | 确认清除本地草稿

前置：[编辑帖子并保留评论](/level/8?task=30)。[查看清空草稿按钮代码](/level/8?guide=1)。

### 操作步骤

1. 按清除草稿示例创建 `clear-draft` 按钮并绑定点击事件。先发一条合成帖，留一条评论。再回发帖区写另一段未发布内容，点「保存草稿」。
2. 点「清空本地草稿」，第一次选取消，再点「恢复草稿」确认仍在。第二次点清空，选择确定，重新打开或刷新网页。
3. 预期草稿表单为空，刚才已发布的帖子和评论仍能读。若发布内容也一起消失，检查监听只把 `state.draft` 改为 `null`，并未清空 `state.posts`。

### 预期结果

取消不改变草稿，确认后草稿消失，帖子和评论仍在。
