# 让树洞页面好读

### 开始前

先打开第 2 关的网页，留着浏览器窗口。样式写进单独的 `styles.css`。保存以后刷新对照，能确认是自己的文件变了。 [上一步](/level/2?task=9)

### 帖子卡片和窄屏 CSS 示例

**CSS** 是用来给网页设置颜色、字体和布局的语言。上一关在 HTML 里写了标题与帖子，这次把外观单独放在一个样式文件。比如 `body { background: #f3f5eb; }` 的意思是「把整页背景变成浅绿色」。`body` 选中要设置的部分，`background` 指背景，井号后是颜色值。

在 VS Code 左侧右键 `web`，新建 `styles.css`。回 `index.html`，在 `</head>` 的上一行加入 `<link rel="stylesheet" href="./styles.css">`。回样式文件粘贴以下内容，两个文件都要保存。先改变页面背景验证链接，再观察卡片排列。

```css
* { box-sizing: border-box; }
body {
  margin: 0;
  background: #f3f5eb;
  color: #20352b;
  font: 16px/1.6 system-ui, sans-serif;
}
header, main { max-width: 920px; margin: auto; padding: 1rem; }
section { margin-block: 1rem; }
.post-list { display: flex; flex-wrap: wrap; gap: 1rem; }
.post-card {
  flex: 1 1 16rem;
  min-width: 0;
  padding: 1rem;
  border: 1px solid #cfdbcf;
  border-radius: .8rem;
  background: #fff;
  overflow-wrap: anywhere;
}
.post-card img { max-width: 100%; height: auto; }
#comment-list { background: #e9efe4; padding: .75rem .75rem .75rem 2rem; }
form { display: grid; gap: .5rem; margin-block: .75rem; }
input, textarea, select, button { font: inherit; }
textarea { min-height: 6rem; }
button { width: fit-content; padding: .4rem .7rem; }
button:focus-visible, input:focus-visible, textarea:focus-visible {
  outline: 3px solid #2b6446;
  outline-offset: 2px;
}
```

在 HTML 的 head 内一并加 `<meta name="viewport" content="width=device-width, initial-scale=1">`。用 Chrome 或 Edge 右键「检查」，点开发者工具左上角的手机图标，选择响应式宽度并输入 360。也可以将浏览器窗拖窄。改一条帖子成很长的标题，确认能换行。若颜色完全没变，检查 `styles.css` 是否和 `index.html` 同目录，两个扩展名是否完整。

## 任务 10 | 引入树洞样式

前置：[准备有来源的补充素材](/level/2?task=9)。[查看帖子卡片和窄屏 CSS 示例](/level/3?guide=1)。

### 操作步骤

1. 打开 VS Code，在左侧 `web` 上点右键，选「新建文件」，命名 `styles.css`。将「帖子卡片和窄屏 CSS 示例」中的 CSS 整段复制进去并保存。在左栏确认它和 `index.html` 在同一层。
2. 回 `index.html` 搜索 `</head>`，点到它上面另起一行，插入 `<link rel="stylesheet" href="./styles.css">`。保存并刷新浏览器。找到 CSS 的 `background: #f3f5eb;`，暂换 `#fff4dc` 再保存刷新。
3. 颜色变化后恢复你喜欢的值。没变化时，核对链接是否写在 `head` 内、文件后缀是否真实，以及两份文件都已保存。

### 预期结果

加上的背景色可见，移除 link 并刷新会回到浏览器默认样式。

### 提交

交 link 标签和生效后的截图。

## 任务 11 | 选择易读的树洞主题

前置：[引入树洞样式](/level/3?task=10)。

### 操作步骤

1. 在 `styles.css` 搜索 `body {`。在该组大括号内找 `background` 和 `color`。先留着文字颜色 `#20352b`，把背景换成 `#eef3fa`，保存刷新，自己读一遍正文。
2. 在样式表末尾另起一行加 `.post-card h3 { font-size: 1.25rem; }`。正文颜色、卡片标题与话题应能一眼区分。用 Tab 移到表单控件，看焦点边框是否仍然清楚。
3. 如文字看着吃力，恢复 CSS 示例里浅背景和深文字的组合。每次只换一个数字并刷新，定位是哪一条生效。

### 预期结果

卡片标题醒目，正文、话题和日期都读得清。

### 提交

交配色和调整后的页面，写一句配色理由。

## 任务 12 | 设计帖子与评论卡

前置：[选择易读的树洞主题](/level/3?task=11)。

### 操作步骤

1. 在 CSS 搜索 `.post-card {`，将这一组的 `padding: 1rem;` 临时改成 `padding: 1.4rem;`，保存刷新。这个属性决定卡片边框和文字之间的空隙。
2. 在 `#comment-list` 中换一个浅色背景，保存刷新并比较卡片与评论是否分得开。回 HTML 把一张标题暂时换成一长串无空格的练习字，正文加至少两句话。
3. 刷新查看长标题是否换行。若内容冲出边框，确认卡片规则有 `min-width: 0` 与 `overflow-wrap: anywhere`，并检查图片宽度规则。验收后将长标题改回自己的内容。

### 预期结果

长标题可换行，评论区有独立背景，任何内容都不会跑出卡片。

### 提交

交正常卡片和长标题的对比。

## 任务 13 | 适配两个窗口宽度

前置：[设计帖子与评论卡](/level/3?task=12)。

### 操作步骤

1. 打开 `index.html`，确认 `<meta name="viewport" content="width=device-width, initial-scale=1">` 在 `head` 中。打开 CSS 搜索 `post-list`，确认有 `display: flex` 和 `flex-wrap: wrap`。保存。
2. 在 Edge 或 Chrome 的网页空白处右键「检查」，点工具栏的小手机图标。可在顶部设备栏选择「响应式」，宽度输入 `360` 并回车。手机图标不在时可以拖窄浏览器窗口，或先用支持设备工具的浏览器。
3. 比较宽屏和 360 像素下的卡片、表单。按 Tab 一次或多次找到一个按钮，观察焦点边框。若卡片强制一排，检查是否写成了 `nowrap`，改为 `wrap`。

### 预期结果

宽屏卡片并排，窄屏顺次叠放，焦点可见，没有整页横向滚动。

### 提交

交两个宽度的页面结果。
