# 让看板在电脑和手机上都放得下
从上关的 `todo-app/index.html` 开始。用 `<div class="card">` 包住现有的标题、介绍、输入和列表，再用 `<div class="entry">` 把输入框与按钮包在一起。在 `head` 中加入 `<link rel="stylesheet" href="style.css">`，在同目录建 `style.css`。

```css
* { box-sizing: border-box; }
body {
  margin: 0;
  min-height: 100vh;
  display: flex;
  align-items: center;
  justify-content: center;
  background: #f0f2f5;
  font-family: system-ui, sans-serif;
}
.card {
  width: min(400px, calc(100% - 32px));
  padding: 20px;
  border: 1px solid #ccd3db;
  border-radius: 12px;
  background: white;
  box-shadow: 0 6px 20px #172a441a;
}
.entry { display: flex; align-items: center; gap: 10px; }
.entry input { flex: 1; min-width: 0; }
```

在浏览器「检查 → 样式」临时取消 `padding`，看是边框移动了，还是文字靠到了边上。把窗口缩到手机宽度，输入框应随窗口收缩，页面底部无需横向滚动。样式一条都没生效时，检查 `href` 与实际 CSS 文件名，再去「网络」面板刷新找 `style.css`。

自己补完标题、按钮和列表样式。调整一项后写下一句观察，例如「改变间距只移动了按钮，没有改变卡片居中」。把可用版本另存为 ZIP，再进入交互阶段。
