# 在本机用一张表保存两条任务
看板的 JS 对象有 text、done、createdAt。为后端约定数据库字段 `title`、`done`、`created_at`，另加由数据库分配的 `id`。标题可以重复，更新和删除应按 id 找到那一条。准备本机的 MySQL Community Server 8.x；先保留只监听本机的学习实例，不接入网站的生产数据。[MySQL 下载](https://dev.mysql.com/downloads/mysql/) · [官方 SQL 入门](https://dev.mysql.com/doc/refman/8.4/en/tutorial.html)

安装时为本机账户设置自己的密码。新开终端运行 `mysql -h 127.0.0.1 -P 3306 -u root -p`，提示时再输入。出现 `mysql>` 后先执行 `SELECT VERSION();`。如果提示找不到 mysql，使用安装目录 bin 中的 mysql 程序；如果提示连接被拒绝，检查本机 MySQL 服务是否已启动、配置端口是多少。

在新的本地学习库执行下面的 SQL。在工作区创建 database 子目录，保存为 `task-board/database/schema.sql`，以后能在另一份练习环境复建表结构。

```sql
CREATE DATABASE IF NOT EXISTS todo_db CHARACTER SET utf8mb4;
USE todo_db;
CREATE TABLE IF NOT EXISTS task (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    title VARCHAR(200) NOT NULL,
    done TINYINT NOT NULL DEFAULT 0,
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);
SHOW TABLES;
DESCRIBE task;
```

再用同一连接练习修改。记录新行编号后用它精确更新，即使原表有其他练习记录也能重做。每条语句以分号结束。

```sql
INSERT INTO task(title) VALUES ('写第一版说明');
SET @first = LAST_INSERT_ID();
INSERT INTO task(title) VALUES ('核对截图');
SET @second = LAST_INSERT_ID();
SELECT id, title, done FROM task WHERE id IN (@first, @second) ORDER BY id;
UPDATE task SET title = '写第二版说明', done = 1 WHERE id = @first;
DELETE FROM task WHERE id = @second;
SELECT id, title, done FROM task WHERE id IN (@first, @second) ORDER BY id;
```

最终结果应只剩「写第二版说明」，done 为 1。再新建一条同名任务，独立用 id 找到其中一条。回想浏览器的字段名和表的字段名，下一关服务端会负责两者的转换。[MySQL 自增编号](https://dev.mysql.com/doc/refman/8.4/en/example-auto-increment.html)

## 任务 52 | 用 SQL 增删改查
按示例单独插入两行，用 `LAST_INSERT_ID()` 留住各自编号。查询两行，仅更新第一行标题并删除第二行，再查相同的两个 id。交实际编号、四类 SQL、两次查询结果，说明为什么自己的语句不会误改同名任务。
