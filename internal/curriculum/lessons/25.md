# 给公开帖子加举报入口

拿第 24 关的同一份仓库继续做。在开发库用两个测试账号分别发布、举报一条虚构帖子。新增 `reports` 表，记录帖子 ID、举报人 ID、原因、可选的补充说明、状态和提交时间。举报人由当前会话决定，客户端只发送 `postId`、`reason` 和可选的 `note`。让原因使用固定选项，例如 `HARASSMENT`、`PERSONAL_INFO`、`SPAM`、`OTHER`。帖子仍可见才接受举报，对同一账号与同一帖子用数据库唯一约束防止双击和并发重复写入。

保留第 22 关的作者删除规则。举报的帖子外键允许在原帖删除后置空，删除事务将尚未处理的举报记为已关闭并记录原因，不在审计中复制帖子正文。

把 `POST /api/reports` 接到帖子详情页。成功用 201 返回 `{ "data": { "id": "7", "status": "OPEN" } }`，使用 401 表示尚未登录，403 表示会话或 CSRF 检查失败，404 表示帖子当前不可用，409 表示已举报。错误正文固定为 `{ "code": "...", "message": "...", "fieldErrors": {} }`。公共帖子响应继续使用前一章合约，且不暴露举报人的账号或备注。举报按钮要给出确认回执，保留原帖阅读位置。

### 举报数据表

**事务**是一组一起成功或一起撤销的数据库写入。**唯一约束**由数据库检查重复值，对连续点击也有效。在 `server/db/05-reports.sql` 保存下表。本地后端停止后用管理员连接选定开发库再运行迁移，再以应用账号执行 `SHOW CREATE TABLE reports;` 观察约束。`status` 初始值 OPEN 表示待处理。

```sql
CREATE TABLE reports (
    id BIGINT NOT NULL AUTO_INCREMENT PRIMARY KEY,
    post_id BIGINT NULL,
    reporter_id BIGINT NOT NULL,
    reason VARCHAR(30) NOT NULL,
    note VARCHAR(300),
    status VARCHAR(20) NOT NULL DEFAULT 'OPEN',
    created_at DATETIME(6) NOT NULL,
    resolution_reason VARCHAR(300),
    CONSTRAINT fk_reports_posts FOREIGN KEY (post_id) REFERENCES posts(id) ON DELETE SET NULL,
    CONSTRAINT fk_reports_user FOREIGN KEY (reporter_id) REFERENCES users(id),
    CONSTRAINT uq_reports_post_reporter UNIQUE (post_id, reporter_id)
);
```

在 `ReportController.java` 定义 `ReportInput(Long postId,String reason,String note)` 与 `ReportReceipt(String id,String status)` 两个 record。Controller 调用同包的 `ReportService.create(input, principal)`。服务用 `CurrentUser.id(principal)` 得到举报人，通过数据库获取目标帖。可复用 `JdbcTemplate`，用 `GeneratedKeyHolder` 记录新行 ID。第一次先用 `posts.findById`，第 26 关引入隐藏状态后改为查询 VISIBLE。接口上的 `@PostMapping("/api/reports")` 接收输入，成功用 `ResponseEntity.status(201).body(Map.of("data", receipt))` 返回回执。

写入时给 `reason` 固定四个值，`note` 最多 300 字符。使用带 `?` 占位符的 INSERT，由数据库生成 UTC 时间。捕获唯一约束冲突后返回 409。另在现有 `PostController.remove` 加 `@Transactional`。删除前先以当前帖子 ID 更新其 OPEN 举报为 DISMISSED，`resolution_reason` 写固定的 `TARGET_DELETED`，然后删除帖子。外键会让保留的举报记录与正文解除关联。

### 举报服务与接口

```java
// GovProblem.java
package edu.campus.treehole;

import java.util.Map;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;

public class GovProblem extends RuntimeException {
    final int status;
    final String code;

    public GovProblem(int status, String code, String message) {
        super(message);
        this.status = status;
        this.code = code;
    }
}

@RestControllerAdvice
class GovernanceErrors {
    @ExceptionHandler(GovProblem.class)
    ResponseEntity<Map<String, Object>> explain(GovProblem error) {
        return ResponseEntity.status(error.status).body(Map.of(
            "code", error.code, "message", error.getMessage(), "fieldErrors", Map.of()));
    }
}
```

```java
// ReportController.java
package edu.campus.treehole;

import java.security.Principal;
import java.util.Map;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;

@RestController
public class ReportController {
    private final ReportService reports;

    ReportController(ReportService reports) { this.reports = reports; }

    @PostMapping("/api/reports")
    public ResponseEntity<Map<String, ReportReceipt>> report(
            @RequestBody ReportInput input, Principal principal) {
        return ResponseEntity.status(201).body(Map.of("data", reports.create(input, principal)));
    }

    public record ReportInput(Long postId, String reason, String note) {}
    public record ReportReceipt(String id, String status) {}
}
```

```java
// ReportService.java
package edu.campus.treehole;

import java.security.Principal;
import java.sql.Statement;
import java.util.Set;
import org.springframework.dao.DuplicateKeyException;
import org.springframework.jdbc.core.JdbcTemplate;
import org.springframework.jdbc.support.GeneratedKeyHolder;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

@Service
public class ReportService {
    private static final Set<String> REASONS =
        Set.of("HARASSMENT", "PERSONAL_INFO", "SPAM", "OTHER");
    private final JdbcTemplate jdbc;
    private final CurrentUser currentUser;

    ReportService(JdbcTemplate jdbc, CurrentUser currentUser) {
        this.jdbc = jdbc;
        this.currentUser = currentUser;
    }

    @Transactional
    public ReportController.ReportReceipt create(ReportController.ReportInput input, Principal principal) {
        Long reporter = currentUser.id(principal);
        if (input.reason() == null || !REASONS.contains(input.reason())) {
            throw new GovProblem(400, "INVALID_REASON", "请选择有效的举报原因");
        }
        if (input.postId() == null || input.postId() < 1) {
            throw new GovProblem(400, "INVALID_POST", "请选择要举报的帖子");
        }
        if (input.note() != null && input.note().length() > 300) {
            throw new GovProblem(400, "NOTE_TOO_LONG", "补充说明最多 300 字");
        }
        var keys = new GeneratedKeyHolder();
        try {
            int saved = jdbc.update(connection -> {
                var statement = connection.prepareStatement("""
                    INSERT INTO reports(post_id, reporter_id, reason, note, created_at)
                    SELECT id, ?, ?, ?, UTC_TIMESTAMP(6) FROM posts WHERE id=?
                    """, Statement.RETURN_GENERATED_KEYS);
                statement.setLong(1, reporter);
                statement.setString(2, input.reason());
                statement.setString(3, input.note());
                statement.setLong(4, input.postId());
                return statement;
            }, keys);
            if (saved == 0) throw new GovProblem(404, "POST_NOT_FOUND", "这条帖子当前不可用");
        } catch (DuplicateKeyException duplicate) {
            throw new GovProblem(409, "REPORT_EXISTS", "这条帖子已收到你的举报");
        }
        Number id = keys.getKey();
        if (id == null) throw new IllegalStateException("Missing generated report id");
        return new ReportController.ReportReceipt(id.toString(), "OPEN");
    }

    public void closeBeforePostDelete(Long postId) {
        jdbc.update("""
            UPDATE reports SET status='DISMISSED', resolution_reason='TARGET_DELETED'
            WHERE post_id=? AND status='OPEN'
            """, postId);
    }
}
```

在 `PostController.java` 添加 `import org.springframework.transaction.annotation.Transactional;`，给原构造函数加 `ReportService reports` 参数和对应字段。把原来的 `remove` 保留注解与身份参数，方法体改成以下三行。将 `@Transactional` 加到该方法上，使处理举报与删帖作为一次数据库动作。

```java
Post post = requireOwnedPost(id, principal);
reports.closeBeforePostDelete(post.id);
posts.delete(post);
```

### 统一身份错误

`GovProblem` 返回业务错误。未登录和写入请求保护由 Spring Security 在进入 Controller 之前处理。在 `SecurityConfig` 最后一个大括号前添加下面方法，再将 `authenticationEntryPoint` 的 `response.setStatus(401)` 替换为 `securityError(response,401,"SIGN_IN_REQUIRED","请先登录")`。将 `accessDeniedHandler` 的 403 同样替换成 `securityError(response,403,"REQUEST_FORBIDDEN","当前请求没有权限")`。消息与代码都来自这里的固定字符串。

```java
private static void securityError(jakarta.servlet.http.HttpServletResponse response,
        int status, String code, String message) throws java.io.IOException {
    response.setStatus(status);
    response.setContentType("application/json;charset=UTF-8");
    new com.fasterxml.jackson.databind.ObjectMapper().writeValue(response.getWriter(),
        java.util.Map.of("code", code, "message", message, "fieldErrors", java.util.Map.of()));
}
```

在 `web/app.js` 末尾加监听。`targetPostId` 在开弹窗时记录，避免把请求发到另一个帖子。`write` 复用 [发布账号区已引入的模块](/level/21?task=78)。

```js
const reportDialog = $("#report-dialog");
let targetPostId = null;
$("#report-post").addEventListener("click", () => {
  if (!activePostId) return;
  targetPostId = activePostId;
  $("#report-form").reset();
  $("#report-error").textContent = "";
  reportDialog.showModal();
  $("#report-reason").focus();
});
$("#report-cancel").addEventListener("click", () => reportDialog.close());
reportDialog.addEventListener("close", () => $("#report-post").focus());
$("#report-form").addEventListener("submit", async event => {
  event.preventDefault();
  const button = event.currentTarget.querySelector('button[type="submit"]');
  button.disabled = true;
  $("#report-error").textContent = "";
  try {
    await write("/reports", "POST", {
      postId: targetPostId,
      reason: $("#report-reason").value,
      note: $("#report-note").value.trim()
    });
    reportDialog.close();
    $("#feedback").textContent = "已收到举报。";
  } catch (error) {
    $("#report-error").textContent = error.message;
  } finally {
    button.disabled = false;
  }
});
```
