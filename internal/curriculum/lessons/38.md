# 用静态文件服务发布看板网页
从能在开发模式打开的 Vite 前端开始。若第 17 关的 package.json 只定义了 dev，先在 scripts 增加 `"build": "vite build"`。在 `task-board/todo-app` 运行 `npm ci`、`npm run build`，查看 `dist/index.html` 里实际引用的 JS、CSS 文件名。把 dist 内的内容上传到练习主机的 `~/todo-site/public`，做成与开发电脑无关的一份静态站点。

以下是 Debian/Ubuntu 上可用普通账户运行的独立 Nginx 实验。使用学校已安装的 nginx，或在自己的虚拟机安装发行版的 nginx 软件包。把配置保存到 `~/todo-site/nginx.conf`，在该目录创建 `logs` 与 `public`。浏览器与应用若在不同机器，可在自己电脑运行 SSH 隧道 `ssh -L 8088:127.0.0.1:8088 student@lab-host`，然后访问自己电脑的 `http://127.0.0.1:8088`。

```nginx
pid logs/nginx.pid;
error_log logs/error.log;
events {}
http {
    include /etc/nginx/mime.types;
    access_log logs/access.log;
    client_body_temp_path logs/client_temp;
    proxy_temp_path logs/proxy_temp;
    fastcgi_temp_path logs/fastcgi_temp;
    uwsgi_temp_path logs/uwsgi_temp;
    scgi_temp_path logs/scgi_temp;
    server {
        listen 127.0.0.1:8088;
        root public;
        index index.html;
        location /assets/ { try_files $uri =404; }
        location / { try_files $uri $uri/ /index.html; }
    }
}
```

在远端的 `~/todo-site` 执行 `nginx -p "$PWD/" -c nginx.conf -t`，显示 successful 后用相同命令去掉 `-t` 启动。用 `curl -I http://127.0.0.1:8088/` 确认首页 200；再从 index.html 拿一条真实 JS 路径单独访问，应返回脚本的 Content-Type。HTML 正常、JS 却返回 HTML 时，检查 dist 是否多套了一层目录。若安装包给普通用户的临时目录权限不足，可在 http 中把 `client_body_temp_path`、`proxy_temp_path` 指向自己有权限的目录。

先独立判断哪个地址能被同学打开：本机回环地址只在本机有效；校园地址需要对应网络；隧道需要使用者自己的授权连接。交付时如实写明可达范围。
