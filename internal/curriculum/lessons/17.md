# 把已有页面接到树洞 API

现在让同一张树洞网页读取 MySQL 中的帖子。**Node.js** 让 JavaScript 在终端运行，**npm** 管理前端使用的工具，**Vite** 提供本地开发服务器。仍然使用自己的 `index.html`、样式和前端 JavaScript。**代理**让浏览器把请求发送给 Vite，再由 Vite 把 `/api/...` 请求转给 Java。浏览器看到的网页与接口使用同一来源，即协议、主机和端口相同。

### 启动开发代理

在终端先运行 `node -v`。本关使用 Vite 7，可使用 Node.js 22.12 及以上的 22.x。已有兼容版本就直接检查 npm。

:::windows

在 [Node.js 下载页](https://nodejs.org/en/download) 选符合要求的版本和处理器对应的 Windows Installer（`.msi`）。双击下载文件，按向导安装并保留把 Node.js 加入 PATH 的设置。关闭并重新打开 VS Code。如果 PowerShell 报 `npm.ps1` 被策略阻止，将本课程 npm 命令开头的 `npm` 换成 `npm.cmd`，参数照写。

:::

:::mac

在 [Node.js 下载页](https://nodejs.org/en/download) 选符合要求的版本，下载 macOS Installer（`.pkg`）。在 Finder 双击安装包，读完许可后按向导完成安装，再重新打开 VS Code 的终端。

:::

:::linux

在 [Node.js 下载页](https://nodejs.org/en/download) 选符合要求的版本和 Linux，再按页面上显示的安装方式和命令操作。如果使用学校预配的 Linux 环境，从教师提供的终端运行版本检查。

:::

安装后重新开终端，用 `node -v` 和 `npm -v` 检查，两条都应显示版本。前端终端从仓库根目录执行 `cd web`。如果已有 `package.json` 就保留，其余同学先运行 `npm init -y`。然后执行 `npm install -D vite@7` 和 `npm pkg set scripts.dev=vite scripts.build="vite build"`。

创建 `web/vite.config.mjs`。`strictPort` 防止端口被占用时悄悄换地址。若你上一关选择另一个后端端口，改这里的 target。

```js
import { defineConfig } from 'vite'

export default defineConfig({
  server: {
    host: 'localhost',
    port: 5173,
    strictPort: true,
    proxy: { '/api': 'http://127.0.0.1:8080' }
  }
})
```

### 共用请求函数

**fetch** 是浏览器发请求的函数，**异步**表示请求过程不阻塞页面。`await` 等结果，`try/catch` 处理失败。建议新增 `web/api.js`。若原入口脚本还未使用模块，把 HTML 中的对应标签加上 `type="module"`，再在 JS 文件开头 import。模块文件之间用相对路径。原页面已有的函数、数据结构和界面可以继续使用。

```js
export async function api(path, { method = 'GET', data, headers = {} } = {}) {
  const response = await fetch('/api' + path, {
    method,
    headers: data === undefined ? headers : { ...headers, 'Content-Type': 'application/json' },
    body: data === undefined ? undefined : JSON.stringify(data)
  })
  if (response.status === 204) return null
  const result = await response.json().catch(() => null)
  if (!response.ok) {
    const error = new Error(result?.message || '请求失败，请稍后重试。')
    error.status = response.status
    error.payload = result
    throw error
  }
  return result
}
```

前端请求统一写 `api('/posts')`。`/api` 前缀由函数添加一次。若浏览器报 "Failed to fetch" 或返回 502，先确认 Java 后端能在 8080 直接返回，再检查本页的代理。[Vite 的代理配置](https://vite.dev/config/server-options#server-proxy)

### 列表和详情接线

把 `web/index.html` 里入口换成 `<script type="module" src="./app.js"></script>`。在 `web/app.js` 顶部写 `import { api } from './api.js';`。保留 `state`、`getVisiblePosts`、`renderPosts` 以及现有 HTML 的 `post-list`、`post-detail` 等 id。把 `state.posts` 的初始值改为 `[]`。

把旧 `showPost(id)` 改名为 `renderPostDetail(post)`。删去开头的查找帖子和空值返回两行，把 `activePostId = id` 改为 `activePostId = post.id`。其余显示标题、正文和评论的代码保留。新增以下两个函数。原来列表上的打开按钮继续调用 `showPost`。在原 `#detail-back` 的 click 事件开头加一行 `detailRequest++;`，这样从详情返回后，迟到的数据不会重新展开面板。

```js
let detailRequest = 0;

async function refreshPosts() {
  $("#feedback").textContent = "正在加载帖子…";
  try {
    const rows = await api("/posts");
    state.posts = rows.map((post) => ({
      ...post, id: String(post.id), comments: [], local: true
    }));
    renderPosts();
    $("#feedback").textContent = "帖子已同步。";
  } catch (error) {
    $("#feedback").textContent = error.message + " 可以刷新重试。";
  }
}

async function showPost(value) {
  const request = ++detailRequest;
  const id = encodeURIComponent(String(value));
  try {
    const [post, comments] = await Promise.all([
      api("/posts/" + id), api("/posts/" + id + "/comments")
    ]);
    if (request !== detailRequest) return;
    renderPostDetail({ ...post, id: String(post.id), comments, local: true });
  } catch (error) {
    if (request === detailRequest) $("#feedback").textContent = error.message;
  }
}

function send(path, method, data) {
  return api(path, { method, data });
}
```

`local: true` 暂时给本机练习显示已有的编辑和删除按钮，第 22 关会从登录归属决定显示。列表 API 暂不提供每帖回复数。把 `renderPosts` 的「几条评论」换成「打开后查看评论」，把第 9 关统计行改为 `state.posts.length + " 条帖子"`。

第 7 关的 `saveData` 现在只写草稿，把其存储语句改为 `localStorage.setItem("campus-treehole:draft:v1", JSON.stringify(state.draft))`。在 `loadData` 只读取新键并给 `state.draft`，不再恢复 `state.posts`。将旧的首次 `renderPosts()` 换成 `refreshPosts()`，保留 `loadData(); fillPostForm(state.draft);`。早期「导出/导入练习数据」留在 v0.2 版本。当前版去掉对应控件和两个事件监听，以免用户以为导入文件能覆盖共享数据库。

### 原表单接到接口

在 `web/app.js` 替换原来的 `publishPost` 函数，保留已有的 `$("#post-form").addEventListener("submit", publishPost)`。用同一个 `send` 函数统一写操作，第 21 关会给它加会话与请求令牌。

```js
async function publishPost(event) {
  event.preventDefault();
  const fields = readPostForm();
  if (!fields.title || !fields.body || fields.title.length > 100 ||
      fields.body.length > 1000 || !Object.hasOwn(categoryLabels, fields.category)) {
    $("#feedback").textContent = "请检查标题、正文与话题。";
    return;
  }
  const button = event.currentTarget.querySelector('button[type="submit"]');
  const oldId = editingPostId;
  if (button) button.disabled = true;
  try {
    const path = oldId ? "/posts/" + encodeURIComponent(oldId) : "/posts";
    const saved = await send(path, oldId ? "PATCH" : "POST", fields);
    editingPostId = null;
    if (!oldId) state.draft = null;
    fillPostForm(!oldId ? null : state.draft);
    saveData();
    await refreshPosts();
    await showPost(saved.id);
    $("#feedback").textContent = oldId ? "修改已保存。" : "帖子已发到树洞。";
  } catch (error) {
    $("#feedback").textContent = error.message;
  } finally {
    if (button) button.disabled = false;
  }
}
```

找到旧 `#comment-form` 的 submit 事件，整段用下面版本替换，避免同时执行本地和在线的监听器。

```js
$("#comment-form").addEventListener("submit", async (event) => {
  event.preventDefault();
  const form = event.currentTarget;
  const id = activePostId;
  const body = $("#comment-body").value.trim();
  if (!id || !body || body.length > 500) {
    $("#feedback").textContent = "请写 1 到 500 个字再发送。";
    return;
  }
  const button = form.querySelector('button[type="submit"]');
  if (button) button.disabled = true;
  try {
    await send("/posts/" + encodeURIComponent(id) + "/comments", "POST", { body });
    form.reset();
    if (id === activePostId) await showPost(id);
    $("#feedback").textContent = "评论已发送。";
  } catch (error) {
    $("#feedback").textContent = error.message;
  } finally {
    if (button) button.disabled = false;
  }
});
```

把 `removeLocalPost` 改为 `async` 函数，保留选帖与确认动作。将确认后的本地数组修改替换为 `await send("/posts/" + encodeURIComponent(post.id), "DELETE"); $("#detail-back").click(); await refreshPosts();`，套在 `try/catch` 中显示失败。原来的编辑按钮回调仍找到 `state.posts` 中相同 ID 并填入编辑框。
