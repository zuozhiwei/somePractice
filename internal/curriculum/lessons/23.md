# 把回复送回楼主的收件箱

**收件箱**让发帖者看到别人对自己帖子的回复。它属于个人数据。`GET /api/me/replies` 从当前会话找到楼主 ID，读取归属给这个人的帖子与相关评论。

### 收件箱三个文件

继续把以下三个文件放在 `edu.campus.treehole`。**Controller** 处理 HTTP。**Service** 处理当前人可以读什么。**Repository** 执行数据库查询。`JdbcTemplate` 是 Spring 提供的 SQL 执行工具。`?` 占位符把参数交给数据库驱动处理，参数无需拼成 SQL 文字。

```java
// ReplyRepository.java
package edu.campus.treehole;

import java.time.LocalDateTime;
import java.time.ZoneOffset;
import java.util.List;
import org.springframework.jdbc.core.JdbcTemplate;
import org.springframework.stereotype.Repository;

@Repository
public class ReplyRepository {
    private final JdbcTemplate jdbc;

    ReplyRepository(JdbcTemplate jdbc) { this.jdbc = jdbc; }

    List<ReplyView> forOwner(Long ownerId) {
        return jdbc.query("""
            SELECT c.id, p.id AS post_id, p.title, c.body, c.created_at
            FROM posts p JOIN comments c ON c.post_id=p.id
            WHERE p.owner_id=? AND c.owner_id<>p.owner_id
            ORDER BY c.created_at DESC, c.id DESC
            """, (row, index) -> new ReplyView(
                row.getString("id"), row.getString("post_id"), row.getString("title"),
                row.getString("body"), row.getObject("created_at", LocalDateTime.class)
                    .toInstant(ZoneOffset.UTC).toString()), ownerId);
    }

    public record ReplyView(String id, String postId, String postTitle,
                            String body, String createdAt) {}
}
```

```java
// ReplyService.java
package edu.campus.treehole;

import java.security.Principal;
import java.util.List;
import org.springframework.stereotype.Service;

@Service
public class ReplyService {
    private final CurrentUser currentUser;
    private final ReplyRepository replies;

    ReplyService(CurrentUser currentUser, ReplyRepository replies) {
        this.currentUser = currentUser;
        this.replies = replies;
    }

    List<ReplyRepository.ReplyView> inbox(Principal principal) {
        return replies.forOwner(currentUser.id(principal));
    }
}
```

```java
// ReplyController.java
package edu.campus.treehole;

import java.security.Principal;
import java.util.List;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;

@RestController
public class ReplyController {
    private final ReplyService replies;

    ReplyController(ReplyService replies) { this.replies = replies; }

    @GetMapping("/api/me/replies")
    public ResponseEntity<List<ReplyRepository.ReplyView>> inbox(Principal principal) {
        return ResponseEntity.ok().header("Cache-Control", "no-store").body(replies.inbox(principal));
    }
}
```

这是从已有评论即时查询的首版，不需要重复存消息。第 26 关补帖子隐藏时会加公开可见过滤。第 34 关再扩成可以标记已读与重试的通知。

在 `web/app.js` 末尾加入以下代码。新请求开始前清空上一次渲染。第 21 关的 `accountEpoch` 在切换身份时增加。保存这一时刻的值，可以让迟到的旧身份结果失效。

```js
let inboxRequest = 0;

async function openInbox() {
  if (!signedIn) {
    $("#account-error").textContent = "登录后可以查看回复。";
    $("#account-username").focus();
    return;
  }
  const epoch = accountEpoch;
  const current = ++inboxRequest;
  const list = $("#reply-list");
  const status = $("#reply-status");
  const retry = $("#retry-replies");
  $("#replies-panel").hidden = false;
  $("#replies-title").focus();
  list.replaceChildren();
  retry.hidden = true;
  status.textContent = "正在加载回复…";
  try {
    const rows = await api("/me/replies");
    if (epoch !== accountEpoch || current !== inboxRequest) return;
    status.textContent = rows.length ? rows.length + " 条回复" : "还没有收到回复。";
    for (const reply of rows) {
      const item = addText(list, "li", "");
      const button = addText(item, "button", reply.postTitle);
      button.type = "button";
      button.addEventListener("click", () => showPost(reply.postId));
      addText(item, "p", reply.body);
      addText(item, "time", new Date(reply.createdAt).toLocaleString("zh-CN"));
    }
  } catch (error) {
    if (epoch !== accountEpoch || current !== inboxRequest) return;
    if (error.status === 401) {
      renderAccount(false);
      $("#account-error").textContent = "登录已过期，请重新登录。";
      $("#account-username").focus();
    } else {
      status.textContent = "暂时无法加载回复。";
      retry.hidden = false;
    }
  }
}

$("#open-replies").addEventListener("click", openInbox);
$("#retry-replies").addEventListener("click", openInbox);
```
