# 把第一个看板交给另一台电脑复现
师父拿到的是一个压缩包，而不是你的编辑器窗口。本关的产出是能独立运行的作品包。保留当前 `todo-app`，在它旁边建 `delivery-check`。

1. 检查入口 `index.html`、引用的 `style.css`、`script.js` 和用到的图片是否都在目录里。写一份 `README.md`，第一行告诉读者解压后打开哪个文件。
2. 把 `todo-app` 打成 ZIP，将它解压到空的 `delivery-check`。关闭开发中的原网页，双击解出目录的入口。核对地址栏里确实有 `delivery-check`。
3. 在副本里添加「试运行」和「交作业」，将后者标记完成。保存一张两项未完成、一张第二项完成的截图。关掉浏览器后重新打开，说明这一版数据是否保留。
4. 为自己设计一个新测试，再交给同伴按 README 做一次；如果对方需要追问某一步，把答案补回 README。

压缩后样式丢失，先在解压目录按 HTML 的相对路径找 CSS；文件夹中若出现只在自己电脑上有效的 `C:\…` 路径，改为项目内路径再重新打包。保留 `todo-app-v1.zip`，进入本地存储阶段前可以从它恢复。

## 任务 24 | 提交你的第一个作品
交可打开的 ZIP 和两张不同阶段的运行截图，标明哪张是添加后、哪张是标记完成后。README 中列出文件职责和完成的操作，再挑一个真实困难说明「怎样复现、怎样定位、怎样验证修复」。验收时请从刚解压的副本现场添加并删除一条新任务。
