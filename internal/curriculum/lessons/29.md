# 把待办 API 做成可以动手试的说明书

打开 `task-board/todo-server/pom.xml`，找到项目正在使用的 Spring Boot 版本，再按兼容表选择 springdoc。使用 Spring MVC 和 Boot 3.5.x 的同学，可在 `<dependencies>` 中加入下面这一段。若前面使用了不同的 Boot 小版本，请先对照官方表。保存后在项目根目录执行 `./mvnw spring-boot:run`，Windows 用 `.\mvnw.cmd spring-boot:run`，看到 Started 后打开 `http://localhost:8080/swagger-ui/index.html`。 [springdoc 兼容表和常见问题](https://springdoc.org/faq.html)

~~~xml
<dependency>
  <groupId>org.springdoc</groupId>
  <artifactId>springdoc-openapi-starter-webmvc-ui</artifactId>
  <version>2.8.9</version>
</dependency>
~~~

在已有的任务列表控制器方法上方加 `@Operation(summary = "列出当前用户的任务")`，由 IDE 导入 `io.swagger.v3.oas.annotations.Operation`。启动后先打开 `/v3/api-docs` 查找这句话，再到 UI 展开 GET 操作。前者是给工具看的契约，后者让同学按契约发出请求。如果 UI 返回 401，请只在本机开发配置允许读取文档和 UI 的静态资源，任务接口沿用原有的身份验证。

## 任务 109 | 引入 Swagger 依赖

在 pom.xml 中添加与现有 Boot 匹配的依赖并重新加载 Maven。在同一次启动中访问 UI 和 /v3/api-docs，后者应包含 paths 和自己项目的列表路径。提交依赖片段、Boot 版本及 UI 中出现该路径的截图。遇到 404 先核对应用端口和 MVC 依赖名称。

## 任务 110 | 为接口添加文档注解

为列表、新建、修改、删除分别写一句描述，标明当前用户能操作哪些数据。给新建请求写一个有效标题示例，并记录空标题的实际错误格式。重启后让同学只看 UI 说出如何新建任务。提交 UI 对应位置与一个请求/响应样例。

## 任务 111 | 用 Swagger UI 调试接口

用本机练习账号登录。若用 Bearer 令牌，给本机 OpenAPI 配置 @SecurityScheme（HTTP、bearer），在受保护接口声明同名 @SecurityRequirement，再点 Authorize 填入本次令牌；若前面用同源会话，先在同源登录后使用该会话。点击 Try it out 创建“文档联调”，再列出任务核对新 id。退出后重试，核对认证失败。提交两次状态码和结论，截图遮住凭据。
