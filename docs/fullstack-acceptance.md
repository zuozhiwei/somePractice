# 江湖地图与全栈课程验收

验收入口为 [学习平台](https://s.somecoder.cn)。学生账号用于体验探索、做题和提交，超级管理员账号 `admin` 用于管理与审核。两类账号在地图上看到的关卡权限不同。

## 早晨验收路线

| 场景 | 操作 | 可以观察到的结果 |
| --- | --- | --- |
| 看懂世界 | 学生登录，选「冒险之旅 → 世界地图」，点击不同地区，再尝试拖动、缩放、沿路移动 | 一张世界地图容纳 8 个营地和 46 个学习关卡。可先去远处看风貌和引路人，锁定关卡会说明先修条件。 |
| 留下足迹 | 到「江湖会试」营地，打开「探索手记」，刷新后重访 | 首次抵达记一次，重访保留原记录。探访与学习经验分开计算。 |
| 开始学习 | 点击「推荐任务 → 配套教程」，再点所属关卡 | 可以查看操作步骤、预期现象和验收标准。学生提交截图、压缩包或自己的分享链接，教师在授权范围内审核。 |
| 找到下一步 | 让一项可重做的练习退回，写明需要补充的证据 | 学生可读到审核意见、修改再交。存在可做的分支时，推荐优先给出可做任务。已通过的任务复习时仍显示通过。 |
| 找回账号 | 在登录页选「找回密码」，输入本人的用户名或绑定邮箱 | 邮箱收到 5 分钟验证码，学生自行设置新密码。成功后旧会话失效。 |
| 人工协助 | 用专用验收账号测试，管理员在用户管理核实身份，选「重置密码」生成恢复码，再让该学生选择「管理员恢复码」 | 15 分钟内可使用一次。生成时原密码仍有效，兑换成功才改密。 |
| 查看个人记录 | 查看「师徒关系 → 我的提交」与「排行榜」，翻到下一页 | 窄屏下内容与卡片边缘留有间距。榜单显示「距榜首」，跨页使用同一个榜首经验值。 |

## 从第一次写代码到交付

| 章节 | 学生带走的作品或证据 |
| --- | --- |
| 初出茅庐 | 可以添加、勾选、删除任务的个人网页 |
| 小试牛刀 | 支持持久化、编辑、筛选和异常数据处理的本地看板 |
| 扎根大地 | 浏览器通过 HTTP 调用 Java 后端，将待办存入 MySQL |
| 开门迎客 | 账户注册、登录、退出、任务归属及两个账号的隔离测试 |
| 千锤百炼 | 统一的接口和错误约定、仓库历史、测试与可操作的 API 文档 |
| 百炼成钢 | 10 万条合成数据的查询计划、索引、缓存、异步导入及前后对照 |
| 独当一面 | 自己或校园练习机上的可复现部署、反向代理、服务管理和验收 |
| 江湖会试 | 同一项功能的需求评审、合并检查、兼容迁移、备份恢复、无障碍复核与独立交接 |

毕业验收看作品、设计取舍和接手人能否独立运行。教学练习延续原有 Java、Spring Boot、MySQL 路线，学习平台本身部署 Go、SQLite 和 systemd。

## 维护边界与验收证据

- 世界地图的道路、镜头、人物和绘制在浏览器运行。服务一次返回可见章节与个性化关卡摘要，任务详情按需读取。首次营地探访在 SQLite 按用户和章节去重。
- 学习业务把探访、任务提交、审核结果及经验入账分开。个人推荐、关卡详情与通过记录使用共同的任务状态判定。已有等级保留，后续晋级参考实际可完成的关卡数。
- 课程发布使用独立命令。46 份教程和 179 份任务说明随发布工具版本保存，原 167 个任务 ID 继续指向历史作业。发现管理员编辑造成的基线冲突时，发布事务回滚。日常编辑仍从后台完成。
- 使用隔离数据库逐项提交并审核 179 项任务，最终达到 46/46 关与 5,720 经验。单独验证了退回、读评语、补交、审核通过，以及桌面和手机访问同一营地后足迹一致。
- 学生邮箱恢复通过候选服务和系统自有邮箱实投实收。已用该验证码设置新密码并核对旧密码、旧会话、重复用码三个结果。外部邮箱的投递情况取决于收件方邮箱和过滤规则。
- 用 MySQL 8.4 执行课程中的建表、10 万行造数、索引对比、备份恢复及可重跑的字段回填。第 44 关的 Java 17 与 JUnit 5 示例分别验证了正常通过和引入错误后的失败。第 41 关的 Compose 文件通过配置检查，本轮没有在学生练习环境启动整套容器。
